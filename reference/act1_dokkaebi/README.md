# 1막 참고자료: 한국 도깨비

1막(도깨비 시장) 디자인과 아트 제작을 위한 참고자료 모음. 기획 기준은 docs/GDD.md, 1막 상세는 docs/DESIGN_ACT1.md를 따른다. 이 폴더는 참고자료이며 기획 문서가 아니다.

## 핵심 원칙: 오니 배제

이 프로젝트의 도깨비는 일제강점기 이전의 한국 도깨비 원형을 기준으로 한다. 아래 세 가지를 항상 적용한다.

1. 원형 기준: 도깨비는 뿔 없는 사람 형상의 존재다. 재물과 풍요를 가져오는 신격이면서 심술궂은 장난꾼이라는 양면성을 가진다
2. 금지 요소: 뿔, 호랑이 가죽 옷, 가시 철퇴(가나보), 빨강/파랑 피부의 지옥 옥졸형 조형. 모두 일본 오니에서 온 것이다
3. 오염된 자료 주의: 해방 이후 교과서와 아동서의 도깨비 삽화 대부분이 오니 이미지의 재생산이다. 근현대 삽화는 시각 참고자료로 쓰지 않는다

상세 근거와 비교표는 01_origin_and_distortion.md 참고.

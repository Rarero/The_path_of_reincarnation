# 시각자료 카탈로그

1막 아트 참고용 시각자료 목록. Cowork(Mac) 환경은 외부망 제한으로 파일을 받을 수 없으므로, Windows 환경에서 아래 절차로 다운로드하고 images/license_log.md에 기록한다.

## 다운로드 절차 (Windows)

1. 아래 목록의 출처 사이트에서 검색 키워드로 유물을 찾는다
2. 상세 페이지에서 공공누리 유형을 확인한다. 제1유형(출처표시)만 다운로드한다. 제2유형(상업적 이용 금지)과 제3유형(변경 금지)은 상용 게임 참고자료로 부적합하므로 제외한다
3. 파일명 규칙으로 저장: images/{출처약어}_{유물명}_{번호}.jpg (예: emuseum_gwihyeongmunjeon_01.jpg). 영문 소문자 snake_case (CONVENTIONS.md)
4. images/license_log.md 표에 파일명, 유물명, 출처 URL, 라이선스, 확인 날짜를 기록한다
5. Wikimedia Commons 파일은 파일 페이지의 라이선스 표기를 확인한다. Public Domain과 CC BY 계열은 참고자료로 문제없다. 주의: 참고(보고 그리기)는 라이선스와 무관하게 자유지만, 이미지를 게임 에셋으로 직접 가공해 넣는 것은 CC BY-SA의 경우 동일조건변경허락 의무가 생기므로 금지한다

## A. 유물: 도깨비 도상 관련

### A1. 부여 외리 문양전 일괄 (보물 제343호)

- 백제 사비기 무늬벽돌 8종. 1937년 부여 외리 절터 출토. 국립부여박물관, 국립중앙박물관 소장
- 이 중 산수귀문전(바위 위에 선 귀형)과 연대귀문전(연꽃 대좌 위의 귀형) 2종이 도깨비무늬 벽돌로 불린다
- 뿔 없이 부릅뜬 눈과 벌린 입, 갈기 같은 털, 사람 몸꼴이라는 점에서 오니와 명확히 다른 한국식 귀형 도상의 대표 사례
- 검색 키워드: 부여 외리 문양전, 산수귀문전, 연대귀문전, 귀형문전
- 출처: [국가유산포털 상세](http://www.heritage.go.kr/heri/cul/culSelectDetail.do?ccbaCpno=1121103430000), [국가유산 디지털 서비스 이미지](https://digital.khs.go.kr/heri/heriDetail.do?ctptUid=13898859732441705662&ctptNo=1121103430000), [위키백과 항목](https://ko.wikipedia.org/wiki/%EB%B6%80%EC%97%AC_%EC%99%B8%EB%A6%AC_%EB%AC%B8%EC%96%91%EC%A0%84_%EC%9D%BC%EA%B4%84)

### A2. 귀면 기와 (귀면와) 각종

- 통일신라 녹유귀면와(국립경주박물관), 각지의 귀면 수막새와 마루기와. 지붕에서 잡귀를 쫓는 벽사 도상
- 명칭 주의: 귀면와를 도깨비 기와로 부르는 것은 후대의 통념이며, 학계에는 용의 정면 얼굴로 보는 용면와설 등 논쟁이 있다. 도깨비 얼굴이라고 단정하는 표기는 피하고, 벽사 도상의 조형(눈, 이빨, 갈기, 소용돌이 문양)만 참고한다
- 검색 키워드: 녹유귀면와, 귀면문 수막새, 귀면기와, 용면와
- 출처: [나무위키: 귀면와 (논쟁 정리)](https://namu.wiki/w/%EA%B7%80%EB%A9%B4%EC%99%80), e뮤지엄에서 귀면 검색

### A3. 얼굴무늬 수막새 (보물 제2010호)

- 신라의 미소로 불리는 경주 출토 사람 얼굴 수막새. 국립경주박물관 소장
- 도깨비 유물은 아니지만, 무섭지 않고 친근한 한국식 귀면/인면 표정의 기준점으로 유용하다. 1막 도깨비 NPC의 표정 톤 참고
- 검색 키워드: 얼굴무늬 수막새, 인면문 원와당
- 출처: [위키백과(영문) Roof-end Tile with Human Face Motif](https://en.wikipedia.org/wiki/Roof-end_Tile_with_Human_Face_Motif), e뮤지엄

## B. 민속: 복식과 사물

원형 도깨비는 사람 형상이므로 복식과 생활 사물이 곧 캐릭터 참고자료가 된다.

- 패랭이(평량자): 도깨비가 쓰고 다닌다는 대표 쓰개. 국립민속박물관 소장품 검색
- 감투, 탕건: 도깨비감투의 실물 참고. 국립민속박물관
- 절굿공이, 도리깨, 빗자루, 부지깽이: 도깨비의 정체가 되는 헌 도구들. 도구가 변신한 디자인의 근거. 국립민속박물관
- 장승(벅수): 도깨비의 외형 묘사(장승 같은 거인)와 통하는 민간 조형. 표정 과장의 참고
- 조선 후기 시장(장시) 풍속: 김홍도 풍속도첩의 장터 그림 등. 시장 배경 레이아웃과 인물 군상 참고. 국립중앙박물관 e뮤지엄에서 단원 풍속도첩 검색 (공공누리 1유형 제공)
- 등불, 초롱, 유기 그릇, 엽전: 시장 소품. e뮤지엄, 국립민속박물관

## C. 무속과 의례

- 제주 영감놀이 사진 자료: 영감(도깨비 신) 광대의 차림(도포, 갓 또는 패랭이, 횃불). 디지털제주문화대전, 국립무형유산원
- 진도 도깨비굿 기록 사진: 국립민속박물관 아카이브, 지역문화대전
- 무신도 중 도깨비/영감 계열: e뮤지엄에서 무신도 검색. 명칭 표기를 반드시 확인

## D. 반면교사 (원형 아님, 비교용)

- 조선어독본(1915) 혹부리 영감 삽화: 오니 이미지 이식의 물증. 스타일 참고 금지, 무엇을 피할지 확인하는 용도로만
- 일본 오니 도상(오니 가면, 지옥 그림): 금지 요소 대조용. 다운로드 불필요, 필요 시 링크만 기록

## 수집 우선순위

1. 부여 외리 문양전 중 산수귀문전, 연대귀문전 (한국식 귀형 도상의 기준)
2. 김홍도 풍속도첩 장터 그림 (1막 시장 배경)
3. 패랭이, 감투, 절굿공이 등 민속 사물
4. 얼굴무늬 수막새 (표정 톤)
5. 영감놀이 의례 사진 (도깨비 NPC 복식)

# 게임 용어와 실제 용어 대응표

docs/systems/BOONS.md가 쓰는 시스템 용어를 실존 용어와 조어로 구분한다. 고증을 지키되 어설픈 독창 명칭을 피한다는 기준(2026-07-25 사용자 방향)의 실행 도구다.

## 1. 판정 기준

| 등급 | 정의 | 표기 방침 |
|---|---|---|
| 실존 | 문헌과 사전에 등재된 용어를 원 뜻대로 쓴다 | 그대로 쓴다. 출처를 이 문서에 남긴다 |
| 전용 | 실존 용어를 게임 맥락으로 옮기되 원 뜻에서 크게 벗어나지 않는다 | 쓴다. 원 뜻과의 차이를 명기한다 |
| 조어 | 실존 용어가 없어 만든 말 | 쓸 수 있으나 조어임을 문서에 명기한다. 실존 용어처럼 보이게 위장하지 않는다 |
| 금지 | 근거가 없거나 오류가 알려진 용어 | 쓰지 않는다 |

## 2. 시스템 용어 대응표

| 게임 용어 | 등급 | 실제 뜻과의 관계 | 근거 |
|---|---|---|---|
| 신내림 | 실존 | 신이 사람에게 내리는 것. 그대로 | 01_musok_basics 1장 |
| 몸주, 몸주신 | 실존 | 무당에게 강신해 영력의 주체가 되는 신격. 게임도 같은 뜻 | 01_musok_basics 2장 |
| 권능 | 전용 | 무속 용어가 아니라 일반 한국어다. 무속 용어로 오인되지 않는 중립어라 오히려 안전하다 | - |
| 신당 | 전용 | 무당이 신을 모시는 자리. 게임에서는 신을 만나는 방. 원 뜻은 무당의 집에 있는 신단이므로 길가의 신당이라는 설정은 원 뜻에서 옮긴 것이다 | 01_musok_basics 6장 |
| 공수 | 실존 | 몸주가 무당에게 내려 하는 말, 신탁. 게임에서는 같은 계열 권능 둘을 조합해 나오는 상위 권능의 이름. 신이 직접 개입한다는 뜻이 통한다 | 01_musok_basics 3장 |
| 겹내림 | 조어 | 표준 용어가 아니다. 내림에 겹을 붙여 두 신이 함께 실린다는 뜻으로 만든 말. 다만 여러 신을 융화시키는 집신제 개념이 실재하므로 개념 자체에는 근거가 있다 | 01_musok_basics 4장 |
| 스침, 실림, 온내림 (등급) | 조어 | 무속에 신의 강도를 나타내는 정형 등급이 없어 조어가 불가피하다. 실림은 신이 실린다는 표현에서 온 자연스러운 파생이고, 스침과 온내림은 만든 말이다 | - |
| 산군 | 실존 | 산신의 이칭. 조합 권능 이름으로 쓸 수 있다 | 02_gods 1장 |
| 조왕중발 | 실존 | 부뚜막에 놓는 정화수 그릇. 유물 이름으로 쓴다 | 02_gods 5장 |
| 삼신 (三神을 환인, 환웅, 단군으로 보는 해석) | 금지 | 민속학계가 한자화의 오류로 기각한다. 근대 대종교 교리 계통이다 | 02_gods 4장 |
| 서낭은 성황의 와전이라는 설명 | 금지 | 명시적으로 기각된 해석이다. 어원은 알 수 없다 | 02_gods 2장 |
| 사해용왕 중국식 명호 (오광 등) | 금지 | 일본 판타지 서적이 출처다 | 02_gods 3장 |
| 상시 계열, 특수 계열 | 조어 | 무속 용어가 아니라 게임 기능 구분이다. 무속 어휘인 척하지 않으므로 안전하다. 몸주가 될 수 있는 4종과 히든 전용 2종을 가른다 | - |
| 별신 | 금지 | 특수 계열의 이름 후보였으나 별신굿의 별신은 몇 년에 한 번 크게 벌이는 마을굿의 이름이고 어원설이 갈린다. 특별한 신격 종류를 뜻하지 않는다 | 2026-07-25 조사 |

## 3. 검토했으나 채택하지 않은 후보

| 후보 | 실제 뜻 | 배제 이유 |
|---|---|---|
| 허주, 허주풀이 | 무당이 될 사람에게 씌는 허깨비와 그것을 벗기는 의례 | 잡귀라는 부정적 의미가 강하다. 실패한 조합의 이름 후보였으나 플레이어 경험을 나쁘게 규정한다 |
| 집신제 | 몸주신과 다른 선신들을 융화시키는 입무제의 한 단계 | 개념은 조합 시스템의 근거로 쓰되(01_musok_basics 4장) 이름으로는 쓰지 않는다. 제의 명칭이라 게임 기능 이름으로 어색하다 |
| 명도, 명두 | 무당이 수호신으로 삼는 청동 거울 | 영호남에서 계집아이의 넋을 뜻하기도 한다. 아동신 소재를 피한다는 원칙에 걸린다 |
| 만신 | 무당의 높임말 | 주인공은 무당이 아니라 신이 깃든 산 자다. 직업 명칭을 붙이면 설정이 어긋난다 |
| 대내림, 신대 | 신을 내리게 하는 장대 | 아직 대응하는 게임 기능이 없다. 향후 기믹이 생기면 재검토 |

## 4. 신 계열 이름 확정 상태

| 계열 | 이름 | 등급 | 비고 |
|---|---|---|---|
| 산신 | 산신 | 실존 | 상시. 문헌에 몸주의 종류로 실제 등장한다. 근거 최상 |
| 조왕 | 조왕 | 실존 | 상시. 가신이라 성격이 다르나 이름은 그대로 |
| 서낭 | 서낭 | 실존 | 상시. 성황과 구분해 민간 마을신앙 쪽으로 쓴다 |
| 삼신 | 삼신 | 실존 | 상시 |
| 도깨비 대장 | 도깨비 대장 | 조어 | 특수. 도깨비는 실존, 대장은 게임 조어다. 제주 영감본풀이의 도깨비 형제 위계(reference/act1_dokkaebi/03 2장)에 개념 근거가 있으나 대장이라는 호칭은 전승에 없다. 영감, 참봉 등 실존 호칭으로 바꿀지는 미결정 |
| 용왕 | 용왕 | 실존 | 특수 |

## 5. 미결정

- 도깨비 대장 계열의 이름. 전승 호칭(영감, 참봉, 배선왕)으로 바꿀지 여부. 영감은 제주 영감놀이의 정식 호칭이라 근거가 확실하나 현대 한국어의 영감과 겹쳐 오해 소지가 있다
- 겹내림을 대체할 실존 용어가 있는지의 추가 조사. 현재로서는 없다고 판단했다
- 등급 이름 3종을 실존 어휘로 대체할 수 있는지. 무속에 정형 등급이 없어 어렵다고 판단했다

## 사용 3원칙

### 1. 실존 신앙이다

산신각 기도, 강릉단오제, 제주 영등굿, 삼신 치성은 지금도 행해진다. 도깨비 설화와 달리 이것은 살아 있는 종교 실천이다. 아래를 지킨다.

- 희화화하지 않는다. 신을 우스꽝스럽게 그리거나 의례를 개그 소재로 쓰지 않는다
- 의례 절차를 그대로 재현하지 않는다. 내림굿, 부정풀이 등의 실제 순서를 게임 연출로 복제하지 않고, 어휘와 개념만 빌린다
- 특정 종파나 실존 무당 개인을 지목하지 않는다
- 도깨비 대장 계열은 예외적으로 성격이 가볍다. 이는 도깨비 자체가 설화적 존재이고 원형에 장난기와 승부욕이 있기 때문이다 (reference/act1_dokkaebi/01). 나머지 세 계열에 같은 톤을 적용하지 않는다

### 2. 성별과 형상을 하나로 통일하지 않는다

다섯 신격 모두 지역과 매체에 따라 성별과 형상이 갈린다. 하나로 고정하면 실제 신앙의 한쪽을 지우게 된다.

| 신격 | 갈리는 지점 |
|---|---|
| 산신 | 남성 우세이나 여산신이 실재한다 (지리산 성모 등) |
| 서낭 | 여서낭 단독이 오히려 압도적이다 |
| 용왕 | 구술과 명칭은 여성 계열(용신할머니, 용궁애기씨), 무신도 도상은 남성 |
| 삼신 | 여성. 다만 할망은 노인이 아니라 큰 여신의 경칭이다. 반드시 노파로 그릴 필요가 없다 |
| 조왕 | 조왕각씨, 조왕할망으로 여신으로 간주되나 사전은 신격이 불명하다고 서술한다 |

게임에서는 계열마다 하나의 형상을 골라야 하지만, 그 선택이 유일한 정답이 아님을 알고 고른다. 선택 근거를 BOONS.md에 남긴다.

### 3. 신격의 영역은 실제로 겹친다

산신, 서낭, 용왕은 현장에서 계통이 겹친다. 산신이 서낭신과 겹쳐 동신이 되고, 용왕은 독립 당보다 서낭당에 협시로 좌정하는 경우가 흔하다. 각 신이 독립된 영역을 가진 판테온은 게임 설계에는 편하지만 고증에는 어긋난다.

겹침을 오류로 보지 말고 설정으로 살린다. 서로 다른 계열의 권능을 겹쳐 받는 겹내림 시스템은 이 겹침 구조와 오히려 정합한다.

## 조사 한계 (게임 개발 환경에서 재확인 권장)

Cowork 환경의 웹 도구로는 자바스크립트 렌더링 사이트의 본문 열람에 실패한 항목이 있다. 아래는 Windows 환경의 일반 브라우저로 재확인하기를 권한다.

- folkency 산신 항목의 산신 성별 변천 서술
- folkency 서낭제와 희생제물 항목의 제물 구성
- folkency 용왕제, 용왕밥, 용왕먹이기 항목
- grandculture의 지역별 산신제, 서낭제, 용왕제, 삼신 사례
- 국립민속박물관 소장 용왕 무신도의 도상 서술

## 이미지 자료

아직 수집하지 않았다. 도깨비 폴더와 같은 방식으로 라이선스를 확인해 수집한다 (reference/act1_dokkaebi/04_visual_catalog.md 절차 참고). 우선 수집 대상은 아래다.

- 산신도 (노인과 호랑이. 조선 후기 작례)

- 조왕중발과 부뚜막
- 삼신단지와 한지 고깔
- 무신도 일반 (국사당 소장품 계열)

## 2. 캐릭터 규격

캐릭터 톤앤매너 기준 (2026-08-04 전면 개정, char_anchor_jeoseungsaja.png 기준):

- 화풍 특징: 저채도 무채색 기조의 의상 대면적, 창백한 회갈색 피부, 저대비 4~5단 램프, 부드러운 어두운 외곽선, 절제된 표정(반쯤 감긴 눈). 밝은 포인트는 소품 1~2개(두루마리, 무기 등)로 제한
- 앵커 실물 채택 (2026-08-05 개정, A안): 앵커 밀도를 인게임에 그대로 가져온다. 기존 "스타일만 적용, 28px 유지" 방침과 32px 소형 재생성안(2026-08-05 오전 결정)을 모두 폐기한다. 32px 재생성 검증 결과 얼굴 뭉개짐과 밀도 붕괴로 기각. 앵커의 PixelLab 원본 캐릭터(id 5a9a7868, 캔버스 176x176, 실물 약 66x91px)를 저승사자 인게임 스프라이트로 직접 사용하고, 모든 캐릭터를 이 밀도 급으로 재생성한다
- 축척 (2026-08-05 개정): 16px = 1m 축척을 폐기한다. 새 축척은 저승사자 실물(91px) 기준 약 48px = 1m 초안으로 두고, 인게임 검증에서 확정한다. 논리 해상도 480x270도 재검토 대상이다(캐릭터가 화면 대비 과대해질 경우 640x360 후보). 배경 조각 크기표와 hub.tscn의 임시 scale은 축척 확정 후 일괄 재계산한다
- 플레이 캐릭터 밀도 확정 (2026-08-07, 사용자 판단): 앵커 실물 밀도(실측 53x86)는 허브 NPC 전용으로 한정한다. 플레이어와 적 등 플레이 캐릭터의 표준은 현행 규격인 76x76 캔버스, 가로 중심 40, 발밑 57이며 실물은 플레이어 26x38, 잡도깨비 24x36, 씨름꾼 19x44다. 근거: 2026-08-05 A안(전 캐릭터를 앵커 밀도로 재생성) 이후의 실제 작업이 전부 이 소형 규격으로 진행돼 채택까지 끝났다(요청서 023 씨름꾼이 대표 사례). 문서만 앵커 밀도를 가리키고 에셋은 전부 소형이라 두 갈래가 벌어져 있었다. 실태를 기준으로 통일한다
- 축척 재정리 (2026-08-07): 위 확정에 따라 플레이 캐릭터가 함의하는 축척은 플레이어 실물 38px를 1.75m로 볼 때 약 22px = 1m다. 48px = 1m 초안은 허브 NPC에만 해당한다. 배경 조각 크기표는 여전히 16px = 1m 기준이라 플레이어 대비 약 26퍼센트 작다. 이 정합은 미해결이며 배경 세션이 다룬다 (art_src/requests/025_player_sword.md A-2)
- 정서: 캐릭터 기본 정서는 절제와 무심함. 해학과 유쾌함은 비례가 아니라 모션, 상황 연출, 소품으로 표현한다

- 비례: 3.5~4등신 통일 (2026-08-04 개정, 기존 2~3등신 SD 폐기). 도깨비 계열도 3~4등신으로 격상해 재생성한다. 2026-08-05 SD(2.5~3등신) 재검토가 있었으나 앵커 실물 채택(A안)으로 앵커의 4등신을 유지한다
- 표정 전달 (2026-08-05 개정): 앵커 밀도에서는 머리가 25px 내외로 커져 반쯤 감긴 눈, 다크서클, 입 모양 등 세부 표정이 인게임 스프라이트에서 직접 읽힌다. 표정을 대화 초상에만 위임하던 방침을 해제하되, 대화 초상은 감정 연출용으로 유지한다
- 방향 규약 (2026-08-05 신설, 사용자 지시): 완전 측면(East/West) 단독 사용을 금지한다. 완전 측면은 갓 챙과 얼굴이 겹쳐 실루엣이 붕괴하고 입체감이 죽는다(메가맨의 사선 스탠딩 참조)
  - NPC: South(정면 내지 정면 사선) 고정. 제자리에서 정해진 모션들을 비규칙적으로 반복하고, 상호작용 시 플레이어 쪽을 향한다. East/West 불필요
  - 플레이어와 적: 대기와 행동은 South-East(우향), South-West(좌향, SE 미러). 이동(보행/주행) 중에만 East/West 측면을 쓴다
  - PixelLab v3는 8방향 고정 생성이므로 South-East가 사선의 실질 단위다. South-West와 West는 미러로 얻는다
- 아웃라인 (2026-08-04 개정): 캐릭터와 상호작용 오브젝트는 어두운 통일 외곽선을 유지하되, 순검정 강제를 해제하고 재질 램프 최저단에 가까운 유채 흑색(흑청, 흑갈)을 허용한다. 내부 선은 절제한다. 아웃라인 유무가 전경/배경 구분 신호라는 규칙(5장)은 유지
- 적과 플레이어는 실루엣만으로 구분 가능해야 한다 (Celeste 원칙). 저대비 화풍에서는 실루엣 명도 분리와 6장 엔진 라이팅이 가독성을 보완한다
- 도깨비 고증 강제 (2026-07-30 신설): 도깨비 계열 캐릭터와 NPC는 reference/act1_dokkaebi/01 6장 체크리스트를 생성 프롬프트와 검수 양쪽에 적용한다. 금지: 뿔, 호피 무늬, 가시 철퇴, 빨강/파랑 단색 피부(오니 조형 전부). 일본 요소 전면 배제: 스모, 마와시, 상투/촌마게, 사무라이, 기모노 (2026-08-04, 씨름꾼 스모 이탈 교정). 기본형: 사람 형상, 더벅머리 총각 또는 패랭이 쓴 장정, 한복, 왼다리가 약한 자세, 방망이는 생산 도구로. AI가 goblin/oni 조형으로 이탈하는 경향이 강하므로 프롬프트에 부정 지시를 명시한다 (9장)

## 3. 색

- 명암 단계: 재질 하나당 4~5단계 램프
- 캐릭터 채도 규칙 (2026-08-04 신설): 캐릭터는 저채도 기조로 배경보다 한 단계 더 눌러 그린다. 의상 대면적은 무채색~저채도, 피부는 창백한 회갈색, 인접 명암 단의 대비를 좁게 유지한다. 고채도 면은 게임 신호(청록 도깨비불, 적색 생기 몰림)와 지정 포인트 소품에만 허용한다. 이 개정은 렌더링 질감에 한정하며 아래 막별 팔레트, 감정 곡선, 배경 무드 기준은 유지한다
- 채도: 중채도 기조 + 난색 포인트. 화면 전체는 앉은 야경 톤으로 누르고, 등불과 이펙트, 상호작용 요소만 난색으로 띄운다 (Katana ZERO 계열). 명계의 이질감과 시장의 활기가 공존하는 구도
- 막별 팔레트 그라데이션 (GDD 10장 유지): 1막 등불 난색, 2막 물길 한색, 3막 무채색과 적색
- 시간 그라데이션 (2026-07-30 확정, GDD 3장. 하늘 소멸 후보를 대체): 런이 하룻밤에서 아침으로 흐른다. 1막은 밤이고 층 진행에 따라 달이 점점 기운다 (L0 하늘 레이어의 달 위치를 층 인덱스에 연동). 2막은 날이 밝은 낮의 계곡 (밝은 한색, 아침 햇살과 수면 반사). 3막은 하늘 없는 현대식 실내 (무채와 적색, 삭막). 1막 유쾌한 밤, 2막 정적이고 밝은 낮, 3막 삭막한 어둠의 감정 곡선
- 도깨비왕 달-눈 연출 (2026-07-30 채택, 히든 보스 한정): 1막 내내 기울던 달이 히든 보스 도깨비왕 조우 시 그의 눈 위치로 들어간다. 달이 사실 도깨비왕의 눈이었다는 반전. 런 내내 왕이 지켜보고 있었다는 서사(BOSS.md 3.3의 "흥미와 경계" 성격)와 맞물린다. 정규 런에서는 일반 달로만 보인다. 구현은 M3 도깨비왕 제작 시
- 팔레트 파일: 전역 팔레트 + 막별 서브 팔레트, .gpl 형식, art_src/palettes/. 실제 색값은 M2 S0 선별에서 추출해 확정한다
- 상위 제약 (2026-07-30 명시): 1막 배경 색은 DESIGN_ACT1 2.4의 색 채널 규약이 우선한다. 청록은 도깨비불 게임 신호, 적색은 생기 몰림 신호로 예약되어 배경 장식에 쓸 수 없다. 등불 발광색은 주황과 호박 계열이 기본이다
- 등불 표현 규칙 (2026-07-30 확정, 청사초롱 절충): 등 몸체 천은 저채도 청홍 계열로 수놓아 시장의 다채로움을 표현한다 (조선 청사초롱 고증). 발광(빛무리)은 주황/호박 단일을 유지해 신호색 예약과 충돌하지 않는다. 고채도 초록/빨강/파랑 발광은 금지

## 5. 디자인 밀도와 배경 가독성

디자인 밀도 (2026-07-29 추가, 레퍼런스 스크린샷 2장 기준. 1장 수집 현황 참고):

- 목표 밀도는 높다. 배경을 비워 두지 않는다. 원경 실루엣(거대 구조물, 나무), 중경 오브젝트, 안개 밴드, 대기 파티클(불똥, 먼지)로 화면을 채운다
- 밀도의 재료는 픽셀 디테일이 아니라 레이어 겹침과 대기 효과다. 안개, 광선, 파티클, 실루엣의 중첩으로 밀도감을 만들고, 픽셀 디테일 자체는 근경과 플레이 레이어에 집중한다. 원경까지 디테일로 채우면 제작량과 가독성이 함께 무너진다
- 전경 지면을 채운다: 풀, 잔해, 낙엽, 노점 소품 같은 지면 디테일로 플레이 레이어 바닥에 밀도를 준다
- 1막 적용: 밤시장의 천막과 등불 줄이 중경, 시장 너머 명계 구조물이 원경 실루엣, 등불 글로우와 안개가 대기 레이어를 담당한다

배경 가독성:

배경/맵 분리 구현 규칙 (2026-08-06 신설, 사용자 지적 반영):

- 위 가독성 규칙이 문서에만 있고 에셋에 반영되지 않아, 배경 가판대와 파괴 가능 좌판이 같은 신호를 내고 있었다. PixelLab 생성물이 검정 아웃라인을 포함해 나오는데 그대로 배경에 썼기 때문이다. 아래 두 파이프라인이 규칙을 강제한다

- 배경 레이어 침전값도 함께 내렸다 (scenes/levels/bg_act1.tscn): 중경 L2Mid (0.54, 0.46, 0.44) -> (0.42, 0.38, 0.50), 근경 L3Near (0.72, 0.63, 0.55) -> (0.60, 0.55, 0.64). 값이 어두워지면서 한색으로 이동해 배경이 뒤로 물러난다

배경 제작 규칙 (2026-07-30 신설, 첫 생성 테스트 교정 반영):

- 시점: 측면 입면(사이드뷰) 고정. 원근, 아이소메트릭, 탑다운 각도, 소실점 깊이 표현을 금지한다. 배경 구조물은 DESIGN_ACT1 2.6의 측면 입면 도식을 기준으로 그린다. 프롬프트에 부정 지시를 명시한다 (9장)
- 픽셀 밀도: 생성 캔버스 크기를 인게임 논리 해상도와 일치시킨다. 화면 논리 해상도 480x270 기준(2026-08-04 1.5배 확대 개정, DECISIONS 참고)으로 배경 조각 하나는 32~256px 폭이 적정하다. 큰 캔버스에 미세 픽셀로 그려진 일러스트풍 출력은 기준 미달로 기각한다. 기준은 ref_pixel_density_* 3장의 굵은 픽셀 감각이다
- 조각 단위 생성: 장면 일괄 생성물은 스타일 탐색과 팔레트 추출 용도로만 쓴다. 실제 배경 에셋은 레이어별, 구조물별 조각(가판대, 씨름장, 노름판, 주막, 등불 줄, 원경 실루엣 밴드)으로 나눠 생성하고 엔진에서 합성한다
- 장면 통합감: 조각들이 한 거리에 있는 것처럼 보이려면 같은 지면선, 같은 팔레트, 같은 광원 방향(등불 상단광)을 공유해야 한다. 요청서에 지면선 높이와 광원 방향을 명기한다
- 루프 애니메이션: 배경에 2~3프레임 순환 애니메이션을 기본 적용한다 (DESIGN_ACT1 2.5). 대상: 등불 흔들림, 천막 자락 펄럭임, 국솥 김, 구경꾼 실루엣의 미세 동작, 노름판 엽전 뒤집기. 플레이 지형(L3)과 배경(L2, L4)의 명도 위계는 유지한 채 배경만 움직인다
- 배경 무드 기준 (2026-07-30 확정, ref_mood_market_night.png): 배경의 최종 인상은 "어둠이 지배하고 광원이 점점이 뜨는 조용한 서정"이다. 채도와 대비를 낮게 눌러 활기는 광원의 리듬으로만 표현한다. 1차 스트립처럼 전체가 밝고 또렷한 화면은 무드 기준 미달이다
- 1막 배경 마스터 (2026-07-30 채택): 조각 세트 합성 검증본이 art_src/style_refs/act1_bg_master.png다. M2 배경 씬 구성의 직접 기준이며, 조각별 채택 셀과 크기, 레이어별 야간 침전 값(모듈레이트 기준), 글로우 색은 요청서 008의 채택 조립 규격 표를 따른다. 핵심 원리: 조각 원본은 플랫하고 밝게 유지하고, 밤에 앉히는 것은 엔진의 레이어 모듈레이트와 라이트가 담당한다
- 배경 렌더 규칙: 배경 구조물(L1, L2)은 검정 아웃라인 없이 저채도 면과 실루엣으로 그린다 (기존 아웃라인 규칙과 일치). 광원 글로우(등불 빛무리, 달무리, 도깨비불 발광)는 에셋에 굽지 않고 엔진 라이팅이 담당한다 (6장). 따라서 에셋 조각은 플랫하고 어둡게 생성하고, 무드 앵커 이미지는 최종 화면 시뮬레이션으로만 쓴다

스케일 규약 (2026-08-02 신설, 인게임 크기 개연성 기각 반영):

- 기준 축척: 16px = 1m. 플레이어 28px = 약 1.75m에서 도출한다. 모든 오브젝트는 실물 크기를 미터로 정한 뒤 이 축척으로 환산해 캔버스 크기를 결정한다
- 1막 근경 오브젝트 크기표 (환산 결과. 요청서에 명기):
  - 가판대(좌판+지붕): 3m -> 높이 48px, 폭 56px
  - 주막(국밥집, 건물): 4.5m -> 높이 72px, 폭 96px
  - 귀문(노드 전환 문): 6m -> 높이 96px, 폭 80px
  - 씨름판(모래판, 지름 8m): 폭 128px, 측면이라 높이 32px 내외
  - 노름판 멍석(2m): 폭 32px, 측면이라 높이 10px 내외
- 인물 굽기 금지: 배경 조각에 사람/도깨비 형상을 굽지 않는다. 배경 속 인물이 캐릭터 스프라이트와 축척이 어긋나면 통합감이 무너진다. 군상 연출이 필요하면 캐릭터 스케일(16px = 1m)의 별도 스프라이트로 분리 제작해 엔진에서 배치한다
- 접지 규칙: 지면에 닿는 조각은 패럴랙스 배속이 1.0에 가까워야 한다 (0.9~1.0). 중경(0.5대)에 두는 조각은 자체 바닥 띠(거리감 있는 뒷골목 지면)를 갖거나 지면 접촉을 숨긴다. 등불 줄처럼 구조물에 매달리는 조각은 매달린 구조물과 같은 레이어에 둔다
- 계단식 깊이 배치 (2026-08-02 확정, 사용자 선호 "입체감 있는 배치"): 배경 조각을 한 지면선에 나란히 두지 않는다. 거리 지면 밴드(街) 위에 앞에서 뒤로 갈수록 바닥선을 올려 배치한다 (근경 전열 340 -> 후열 326~330 -> 중경 312 순). 뒤 조각의 상단이 앞 조각 위로 보여 완전 가림을 막고 지면 평면의 깊이를 만든다. 같은 레이어 안에서도 바닥선 차등을 준다. 원경 실루엣도 같은 규칙으로 올린다 (바닥선 292)
- 원근 크기 차등 (2026-08-02 추가): 깊이 열마다 크기를 줄여 베이크한다. 근경 전열 1.0, 근경 후열 0.85, 중경 0.7. 런타임 스케일이 아니라 S2 다운스케일로 굳힌 별도 에셋을 쓴다 (비정수 런타임 스케일 금지 유지)
- 반복 티 방지: 같은 조각을 동일 간격으로 이어 붙이지 않는다. 등불 줄은 기둥 구간별로 처짐, 등 간격, 등 순서를 변주한 512px 연속 밴드로 조립한다 (bg_lantern_band, 절차 조립 스크립트)

## 6. 광원 연출

- 적극적 엔진 라이팅: Godot 2D 라이트(PointLight2D 등)와 그림자를 본격 사용한다. 등불 글로우, 신내림 이펙트 발광, 방 분위기 조명을 엔진이 담당한다
- 스프라이트 생성 원칙: AI 생성물은 플랫(알베도) 기준으로 만든다. 스프라이트에 강한 라이팅을 구워 넣지 않는다. 조명은 엔진이 얹으므로 이중 조명을 피한다
- 팔레트 통제와의 관계: 엔진 라이팅이 최종 화면색을 바꾸므로, 팔레트 판정은 스프라이트 단독이 아니라 라이팅 적용된 인게임 화면 기준으로 한다
- 노멀맵 스프라이트(입체 라이팅)는 선택 실험 항목. M2에서 등불 1개 방으로 효과 대비 비용을 판단한다
- 구현 영향: 방 씬에 라이트와 오클루더 배치 작업이 추가된다. M2 방 템플릿 제작 시 라이트 배치를 규격에 포함한다 (ROOM_SPEC 갱신 후보)

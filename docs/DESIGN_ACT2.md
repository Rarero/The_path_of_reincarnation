# 2막 이무기 물길 디자인 (D3)

최종 수정: 2026-07-24
상태: 1차 (컨셉 수준. 수치는 전부 초안이며 확정 시점을 각 항목에 명시)
상위 문서: docs/GDD.md 3, 7, 9장 / docs/RUN_STRUCTURE.md 3장 2막, 10장 점수제 / 형식 기준: docs/DESIGN_ACT1.md
막 정체성: 플랫포밍. 톤: 장엄한 물길, 한색 팔레트. 수직 구간이 핵심

개정 예고 (2026-07-30, docs/DECISIONS.md): 두 가지 방향 변경으로 본 문서는 전면 재정합 대상이다. 재정합 세션 전까지 본문은 참고용으로만 읽는다.

1. 톤: 밤의 달빛 물길에서 "밝은 낮의 고요한 계곡(폭포, 산길, 정원)"으로 변경. 시간 그라데이션(GDD 3장) 도입으로 2막은 날이 밝은 구간이다. 밤하늘, 달빛 주광원 서술은 아침 햇살과 수면 반사 기준으로 개정한다
2. 구조: 수직 등반 정체성 폐기 (완전 수평화). 1~3막은 이승과 멀어지는 수평 여정이며 탑 구조가 아니다. 등반 마디, 상승 기류, 폭포 역류, 수위 상승 등반 강제(이무기 보스전 포함)는 수평 기준으로 재설계한다. 침수/배수, 감전 수면, 징검다리 등 수평에서 성립하는 기믹은 유지 후보다. "위로 오를수록 하늘이 밝아진다" 레이어 규칙도 폐기한다

## 1. 개요

- 2막은 이무기가 점거한 삼도천 물길을 거슬러 오르는 구간이다. 정체성은 플랫포밍이며, 전투 밀도를 1막보다 낮추고 지형 난도가 부담을 대신한다. 위로 오른다는 감각(수직 등반)을 방 내부와 배경 연출로 전달한다 (노드 맵 UI는 가로 배치 공통 규칙, 2026-07-24 결정 준수)
- 낙사 즉사 없음 (1막과 동일 원칙 유지). 낙하하면 최하단 수면에 착수하며 피해가 없다 (감전 수면 상태 제외). 낙하의 비용은 체력이 아니라 등반 진행 손실이다
- 상승 보조 기믹(상승 기류, 폭포 역류)의 규격과 채택 여부는 M1 조작 검증 결과에 따라 조정될 수 있다. 이 문서의 관련 수치는 전부 초안이다
- 바이옴 스코프: 바이옴 1개(삼도천 물길) + 구간 테마 3종(여울 나루, 폭포 절벽, 침수 굴). 테마는 동일 타일셋의 변형과 수위 상태 차이로 처리한다. 막당 바이옴 1~2개 규칙 안에서 1개로 시작한다

## 2. 배경 풍 (시각 컨셉)

아트 제작이 아니라 방향 정의다. docs/ART_PIPELINE.md 5장 에셋 요청서의 입력으로 옮길 수 있게 쓴다. 2막 배경은 수직 스크롤이 기본이므로 레이어는 세로 타일러블로 설계한다.

### 배경 레이어 구성 (5층, 수직 스크롤 대응)

| 레이어 | 내용 | 비고 |
|---|---|---|
| L0 하늘 | 협곡 위로 좁게 열린 밤하늘, 달빛 기둥 | 위로 오를수록 하늘 비중이 커지고 밝아진다. 등반 진행감의 광원 장치 |
| L1 원경 | 맞은편 협곡 절벽 실루엣, 강 건너는 원혼 행렬의 등불 점광 | 심남색 실루엣. 세로 타일러블. 장엄한 톤의 핵심 |
| L2 중경 | 대폭포 줄기, 물안개 층, 부서진 잔교와 난파선 실루엣 | 폭포 스크롤 애니메이션의 핵심 레이어 |
| L3 근경 | 플레이 지형: 절벽 바위, 잔도, 이끼, 징검다리 | 게임플레이 가독성 최우선 |
| L4 전경 | 물보라, 흩날리는 물방울, 옅은 안개 | 반투명, 드물게. 화면 가림 최소화 |

### 팔레트 방향

- 베이스: 심남색에서 청록의 한색. 아래(깊은 물)일수록 어둡고 위로 갈수록 밝아지는 수직 그라데이션으로 등반 진행감을 색으로도 전달한다
- 주광원: 수면 반사광과 달빛. 저채도 청백. 1막의 난색 활기와 대비되는 장엄하고 고요한 인상
- 게임플레이 신호 색 채널 (2막 정의)
  - 포말 백색: 발판, 상승 기류, 폭포 역류의 가시화 전용. 플랫포밍 가독성의 핵심 채널
  - 금색: 여의주 조각과 보상 신호 전용. 2막의 유일한 난색 포인트 (보스 서사와 직결)
  - 황록 스파크: 감전 수면 경고 전용
  - 적색: 생기 몰림(데스매치) 연출 전용 예약 유지 (RUN_STRUCTURE 9장, 물이 끓어오르는 연출). 평시 사용 금지
- 1막 신호 채널과의 관계: 1막에서 청록은 도깨비불 발판 신호였다. 2막은 베이스 자체가 한색이라 청록을 신호로 쓸 수 없으므로 발판 신호를 포말 백색으로 이관한다. 막별 신호 색 일람표 통합 검토는 D5에서 수행한다
- 테마별 변조: 여울 나루는 수면 반사로 가장 밝음, 폭포 절벽은 물안개 청백, 침수 굴은 저조도에 발광 물꽃 점광원

### 폭포와 수면 표현 방향

- 폭포: 세로 타일러블 스트립 + UV 스크롤, 상단과 하단에 포말 파티클. 셰이더 효과는 픽셀아트 톤을 지키는 계단 양자화 범위 안에서만 사용한다
- 수면: 상단 1~2타일의 하이라이트 라인과 반사 흔들림으로 표현. 수중은 색 오버레이와 느린 부유 입자
- 수위 변화: 수면 라인 이동 + 차오름 포말 연출. 감전 상태는 황록 스파크 오버레이 + 경고음
- 폭포 역류(상승 통로)는 일반 폭포와 시각적으로 구분한다: 역류 줄기는 포말이 위로 흐르고 백색 강조가 들어간다

### 대표 배경 오브젝트

- 나루 잔교와 부서진 나룻배: 삼도천 도하의 흔적. 이무기 점거 이후 끊긴 뱃길의 서사
- 용왕당 돌탑과 금줄: 신성 구역 신호. 1막 장승/금줄과 동일 문법 (신당, 보물 주변)
- 물레방아 잔해, 우렁 껍데기 무더기: 물길 생활의 폐허 소품
- 발광 물꽃: 침수 굴 테마의 점광원. 근경 장식이자 저조도 구간 가독성 보조
- 원혼 행렬 등불: L1 원경 전용. 근경 배치 금지 (1막 손님 실루엣과 동일 원칙, 적과의 혼동 방지)

## 3. 맵 풍과 레벨 디자인 문법

### 이동 규격 (점프 3.5타일 파생, 초안)

| 항목 | 기준 (초안) | 확정 시점 |
|---|---|---|
| 오를 수 있는 단차 | 최대 3타일 (1막과 동일) | M1 |
| 필수 경로 수평 갭 | 점프 단독 4타일 이하 | M1 (대시 거리 확정 후) |
| 대시 요구 갭 | 선택 경로(보상, 비밀)에만 허용 (1막과 동일) | M1 |
| 벽 점프 샤프트 폭 | 3~5타일 (좁을수록 쉬움) | M1 |
| 상승 기류 상승 높이 | 기류 1개당 최대 8타일 | M1 |
| 폭포 역류 상승 | 역류 줄기 1개당 최대 12타일, 중간 이탈 가능 | M1 |
| 부서지는 징검다리 | 밟은 뒤 약 1초 내 붕괴, 약 3초 뒤 재생 | M1 |
| 낙하 | 즉사 없음. 최하단 수면 착수 (감전 상태 제외 피해 없음) | 설계 확정 |

- 벽 점프는 2막 필수 경로의 핵심 기술이다 (1막에서는 골목 한정이었던 것을 승격). 대시는 선택 경로 전용 원칙을 유지한다

### 수직 등반 문법

- 등반 마디: 수직 구간은 마디 단위로 설계한다. 마디 높이 최대 10~14타일(초안), 마디 사이에 안전 턱(넓은 상시 발판)을 둔다. 낙하 손실은 최대 1마디로 통제되어 반복 스트레스를 막는다
- 상승 보조 기믹(기류, 역류)만으로 잇는 구간은 최대 2연속. 사이에 상시 지형을 둔다 (1막 도깨비불 연속 3 제한과 동일 문법, 보조 기믹은 더 보수적으로)
- 부서지는 징검다리는 필수 경로 사용 허용 (낙하 = 마디 손실이라 실패 비용이 시간). 선택 경로에는 제약 없음
- 상승 기류: 진입 시 상승, 이탈 자유. 기류 안에서는 새 원혼의 급강하가 빗나간다 (6장). 등반 중 안전 축 역할
- 폭포 역류: 역류 줄기 안에서 지속 상승하는 통로형 기믹. 기류보다 길고 경로가 고정적이다. 줄기 중간의 장애물(바위, 우렁 포탑)을 피하는 조향이 챌린지가 된다
- 벽 점프 샤프트: 마주 보는 두 벽을 오가는 등반. 벽면의 물이끼 구간(초안: 미끄러짐 가속)과 돌출 바위(휴식 지점)로 리듬을 만든다. 물이끼 채택 여부는 M1 체감 후 결정

### 침수와 배수 (지형 변화 규칙)

- 수위 상태 3단계: 저수(기본), 중수, 만수. 방마다 사용할 단계 수를 정한다 (전 방이 3단계를 쓰지 않는다)
- 전환 트리거: 수문 오브젝트(레버 또는 타격), 전투 웨이브 시작, 보스 페이즈. 자동 시간 변화는 쓰지 않는다 (플레이어가 원인을 읽을 수 있어야 한다)
- 전환 연출: 즉시 변하지 않고 수 초에 걸쳐 차오르거나 빠진다. 차오르는 물에 끼임 피해 없음 (밀어올림 처리). 익사 없음
- 설계 문법: 같은 방을 두 상태로 설계한다. 침수 시 상부 수면 경로가 열리고, 배수 시 바닥의 숨은 경로와 보상이 노출된다. 하나의 지형에서 두 겹의 경험을 얻는 것이 침수/배수의 목적이다
- 수중 이동: 헤엄 (이동 느림, 대시는 짧은 유영 대시로 대체). 수중 전투는 근접 위주로 약화된다. 상세 규칙은 M1/M2에서 확정
- 감전 수면: 수면 전체가 위험 상태가 되는 기믹. 정의는 6장

## 4. 맵 크기와 노드 수 (2026-07-24 갱신)

- RUN_STRUCTURE 기준(10층 + 보스, 층당 노드 2~5)을 따른다. 2026-07-27 구조 개정 반영: L4 신당 보장, L5 중간보스 고정층(강제 조우), L7 신당 보장(신설), L9 상점 보장, L10 쉼터 고정층(보스 직전 휴식). 시간 예산 약 12.2분, 기준치 2막 B = 0, 허용 폭 105
- 2막 히든 보스 용왕 (2026-07-27 방향 확정, 설계는 이 문서 재정합 세션): 특수 계열 용왕 권능은 히든 보스 격파 보상으로 열린다 (docs/systems/BOONS.md 2장). 이무기(승천 실패해 물길을 막은 존재)와 용왕(물길의 주인)의 관계를 서사로 붙일 여지가 있다. 이 결정으로 "용왕이 히든 전용이라 2막 감전 수면 시너지가 대부분의 런에서 발동하지 않는다"는 기존 확인 필요 항목의 조건이 바뀌었으므로 재정합 시 함께 판단한다
- 노드 맵 UI는 가로 배치. 수직 정체성은 맵 UI가 아니라 방 내부(등반 챌린지)와 배경(수직 그라데이션, 폭포)이 담당한다. 이벤트는 전용 노드 종류다(수식 방식 폐기), 플랫포밍 노드 자리를 이벤트 노드가 대체하며 등반 챌린지는 전투방과 이벤트방 내부 지형으로 흡수한다
- 후속 재정합 필요(이 문서): 10층 기준 적 배치 밀도(5장), 이벤트 노드 콘텐츠 이관(8장), 템플릿 목록(11장). 권위 있는 구조는 RUN_STRUCTURE.md 2~3장, 10장
- 방 크기 등급 (초안, 타일 단위. 방 규격 문서에서 확정)
  - 소형 (선택방): 가로 20~24, 세로 12~14
  - 중형 (여울형 전투 기본): 가로 28~36, 세로 16~20
  - 수직형 (절벽 전투, 등반 플랫포밍, 아레나): 가로 18~26, 세로 28~40
  - 보스 아레나: 수직 샤프트 대형 (세로 40 이상, M3 확정)
- 수직형 방은 세로가 가로보다 큰 2막 고유 규격이다. 카메라와 방 연결 규격에 미치는 영향은 방 규격 문서 작성 시 검토한다

| 새 원혼 | 공중 압박 (급강하) | 개방 상공, 수직 샤프트 |

- 1막 5종 대비 3종으로 적고, 방당 적 수도 1막보다 낮게 잡는다. 플랫포밍 막의 부담은 적이 아니라 지형이 담당한다 (전투방 기준 60초는 유지하되 웨이브 규모로 조절)

### 방 유형별 배치 규칙

- 전투방 (기준 60초, 웨이브 1~2개)
  - 여울형: 물고기 원혼 중심 + 우렁 포탑 0~2 (수면 + 발판 지형)
  - 절벽형: 새 원혼 중심 + 우렁 포탑 벽면 부착 (수직 다단 지형)
  - 침수형: 물고기 + 새 원혼, 수위 전환이 전장을 바꾼다 (침수 굴 테마)
- 플랫포밍방: 우렁 포탑 소수 고정 배치만 (경로 방해 역할). 물고기 원혼, 새 원혼 배치 금지 (1막의 "플랫포밍방은 등불 도깨비만" 규칙과 동일 문법)
- 선택방 (신당, 상점, 보물): 적 배치 없음. 안전 공간의 신뢰 유지
- 층 진행 밀도: L1 물고기 단일 (워밍업 고정층), L3 2종 조합, L6 2종 조합, L8 최대 3종 (보스 전 최고 밀도. 단 총 적 수는 1막 L8보다 낮게)

### 조합 규칙

- 새 원혼은 웨이브당 최대 2, 동시 급강하 금지 (시차 강하)
- 물고기 원혼은 수면이 있는 방에만 배치한다 (설정 정합과 기믹 성립 조건)
- 우렁 포탑은 방당 최대 3 (고정 위협 과밀 방지)
- 3종 동시 배치는 L8 전투방에만 허용

## 6. 적 기믹 (행동 패턴 상세, 컨셉 수준)

공통 원칙 (1막과 동일): 모든 공격은 명확한 예비동작을 가진다. 생기 몰림 발동 시 눈빛이 적색으로 변한다.

### 물고기 원혼 (유영)

- 수중을 유영하며 배회. 플레이어가 수면 근처나 수중에 있으면 가속 접근한다
- 도약 물기: 수면 파문과 그림자 예비동작 후 포물선으로 물 밖 도약. 발판 위 플레이어를 노리는 주력 패턴
- 물 밖에서는 느리고 취약하다. 착지 후 퍼덕임 경직 (반격 윈도우)
- 동시 도약은 최대 2 (1막 잡도깨비 순차 돌진과 동일한 다굴 통제 문법)
- 감전 수면에서 기절하고 도약이 봉인된다

### 우렁 포탑

- 바닥, 벽면, 천장에 부착된 고정 포탑. 포물선 수포탄을 발사하며 착탄 지점을 표시한다 (1막 등불 도깨비의 투척 문법 재사용)
- 피격 또는 근접 시 껍데기를 닫는다 (무적). 일정 시간 뒤 다시 열리는 주기가 딜 타이밍 학습을 만든다
- 처치 시 빈 껍데기가 남아 1회용 발판 겸 엄폐물이 된다. 적 처치가 플랫포밍을 돕는 시너지 (1막 등불 도깨비 처치 시 점등 문법의 2막 번역)
- 감전 수면 위의 우렁은 감전 지속 동안 닫힌 채 무력화된다

### 새 원혼 (급강하)

- 상공을 선회하다 목표 위에 그림자와 조준선을 표시한 뒤 급강하한다
- 지면이나 벽에 충돌하면 박혀서 경직된다 (반격 윈도우). 수면에 닿으면 강하를 끝내고 재상승한다 (수중 추격 없음)
- 상승 기류 안의 플레이어에게는 강하 궤도가 흐트러져 빗나가기 쉽다. 기류가 등반 중의 안전 축이 되도록 하는 의도된 상호작용
- 웨이브당 시차 강하 최대 2 (5장 조합 규칙)

### 감전 수면 규칙 (기믹 정의, 용왕 계열 상호작용 포함)

- 발생원: 부정 이벤트(감전 폭우, 8장), 일부 중간보스와 보스 패턴, 플레이어의 번개 속성 공격
- 전도 규칙: 번개 속성 피해가 수면에 닿으면 이어진 수면 전체가 일정 시간 감전된다. 감전 중 수면에 접촉한 모든 개체(적과 플레이어 쌍방)가 피해와 경직을 받는다
- 시각 신호: 황록 스파크 오버레이 (2장 색 채널). 발동 직전 짧은 예고 스파크를 준다
- 용왕 계열 권능(GDD 7장: 지형과 방어, 고유 축은 젖음 상태) 상호작용
  - 용왕은 특수 계열이다 (2026-07-25 개정, docs/systems/BOONS.md 2장). 몸주가 될 수 없고 액티브를 주지 않으며, 2막 히든 보스 용왕을 격파해야 만난다 (2026-07-27 개정, 저확률 별도 경로 병존). 따라서 아래 시너지는 대부분의 런에서 발동하지 않는 보너스다. 감전 수면 기믹 자체는 용왕 없이도 성립하는 지형 기믹이므로 설계 전제가 무너지지는 않는다
  - 용왕의 고유 축은 젖음 상태다. 젖은 적에게 감전이 통하는 구조로 두면 물과 번개가 하나의 축에서 파생된다. 번개는 주력이 아니라 파생이다
  - 용왕 계열 권능을 보유하면 감전 수면 피해 감소, 티어가 높을수록 감소폭이 커진다 (초안). 확정은 M2 권능 구현 시
  - 적 유발 감전과 플레이어 유발 감전은 같은 규칙을 쓴다 (쌍방 대칭). 용왕 권능을 얻은 런에서는 적의 감전 패턴까지 무력화하는 카운터가 된다
  - 후속 필요: 용왕이 히든 전용이 되면서 이 절의 시너지 비중을 재검토해야 한다. 젖음 상태를 용왕 없이도 지형이 부여하는 방향으로 넓히면 시너지가 사문화하지 않는다 (2막 재정합 항목)
- 밸런스 가드: 수면 전투방이 용왕 빌드에서 자동 승리가 되지 않도록 감전 지속시간과 재전도 쿨다운을 둔다. 수치는 밸런싱 단계
- 적별 반응: 물고기 원혼 기절, 우렁 포탑 무력화(닫힘), 새 원혼은 수면에 없으므로 무관. 감전이 3종 중 2종의 카운터이므로 지속시간을 짧게 시작한다

### 엘리트 변형에 관하여

- 엘리트(강화 일반몹) 개념은 2026-07-23 결정으로 폐기되었다 (docs/DECISIONS.md). 개체 강화 변형 대신 중간보스 풀(7장)이 그 역할을 담당한다

## 7. 중간보스 풀 (후보 7종)

배치 규칙은 RUN_STRUCTURE 기준을 따른다 (2026-07-24 갱신): 중간보스 고정층 L5에서 강제 1회 조우, 그 층에 서로 다른 개체와 전투 유형(순수/기믹/이벤트형)의 노드 2~3개를 제시해 플레이어가 고른다. 아레나(2종)와 개체는 분리 제작한다. 수직 지형 활용 유형(기믹 파훼형)을 포함한다. 진입 시 소회복, 이벤트형은 데스매치 타이머 제외.

- 중간보스는 데스매치 150초 발동(초안)을 따른다 (RUN_STRUCTURE 9장)

## 9. 보스: 이무기

### 컨셉

- 용이 되지 못한 큰 구렁이. 천 년 수행 끝에 승천 문턱에서 여의주가 깨졌고, 조각이 저승 곳곳에 흩어졌다. 삼도천 물길을 막고 조각을 긁어모으는 중이다
- 여의주 조각(메타 재화, GDD 5장 "이무기가 흩뿌린 조각")의 기원 서사. 플레이어가 런마다 모으는 조각은 이무기의 실패한 비원의 잔재다
- 명부에 없는 자의 생기가 조각을 끌어당기는 것을 느끼고 적대한다. 조각을 든 주인공은 이무기에게 도둑이자 먹이다
- 성격: 관료가 아니라 집착과 비원의 짐승. 1막 구역장(장사꾼 관료)과 3막 시왕(재판 관료) 사이에서 톤 대비를 만든다. 대사는 1~2줄 상한 (Dead Cells 상한 준수)

### 아레나

- 폭포 우물: 수직 샤프트 대형 아레나. 벽면 발판 다단 + 중앙 수면. 페이즈에 따라 수위가 상승한다
- 벽면에 상승 기류와 폭포 역류가 배치되어 2막에서 학습한 등반 기술이 보스전의 언어가 된다

### 페이즈 구조 (3페이즈)

| 페이즈 | 이름 | 패턴 |
|---|---|---|
| 1 | 물속의 왕 | 저수위. 수면 유영 후 도약 물기 (착수 지점 표시), 몸통 후려치기, 물결 파도 (점프 회피). 하단 발판 위의 기본 전투로 패턴 학습 구간 |
| 2 | 오르는 물 | 수위 상승 시작, 하부 발판이 차례로 침수된다. 위로의 등반이 강제된다 (수직 정체성의 보스전 번역). 이무기는 벽을 감고 오르며 낙석을 떨구고 수면을 감전시킨다 (황록 신호). 벽을 감고 지나가는 몸통의 역린(약점 비늘)을 노리는 딜 타이밍 |
| 3 | 미완의 승천 | 만수위, 좁은 최상단부. 물이 끓어오르는 광폭화 연출 (생기 몰림 적색, RUN_STRUCTURE 9장 연출 규정과 통일). 급강하 물기, 전신 방전, 여의주 조각 폭풍 (조각이 금색으로 빛나며 날아드는 탄막. 이무기의 비원에 공명하는 서사 연출) |

- 격파 시 이무기는 소멸하지 않고 물속 깊이 가라앉는다. 회차 런에서 재전, 배후 떡밥(명부 훼손) 대화 여지를 남긴다 (GDD 2장)
- 미결정: 보스전에 생기 몰림(데스매치) 타이머를 적용할지 여부. 1막 구역장과 동일한 미결정 항목으로 유지한다 (M2 구현 전 결정, docs/DESIGN_ACT1.md 9장)

## 10. 클리어 보상

RUN_STRUCTURE 5장 보상 소스 표와 정합. 수치는 상대 등급(소/중/대)으로만 표기하고 밸런싱 단계에서 확정한다.

| 방 유형 | 보상 (초안) |
|---|---|
| 전투방 | 엽전 소~중 + 낮은 확률 무기. 배수 상태의 바닥 탐색 보상 (침수/배수 문법 연계) |
| 플랫포밍방 | 엽전 소 + 경로 이탈 지점 탐색 보상. 플랫포밍 막 정체성에 맞춰 탐색 보상 비중을 1막보다 높인다 |
| 신당 | 권능 3택 1. 몸주신 계열 최소 1개 포함 가중치 (L4 선택 보장) |
| 중간보스 | 권능 3택 1 또는 상급 무기 택 1 + 엽전 중 |
| 상점 | 구매처: 소모품, 강화 중심 (1막 대비 무기 비중 낮음. 2막은 소모품 보충 구간) |
| 보물방 (확률 등장) | 무기 또는 소모품 묶음 + 엽전 중, 무상. 침수 변형에서 대왕 자라 조우 확률 (7장) |
| 보스 (이무기) | 권능 확정 1 (몸주신 계열 가중) + 여의주 조각 대 + 엽전 대. 클리어 후 지옥문으로 |

### 여의주 조각과 엽전 순환

- 여의주 조각: 이무기가 기원인 재화이므로 이무기 보스 드랍량을 전 보스 중 최대로 둔다 (서사 정합). 2막 비밀방의 조각 획득도 소폭 가중 (초안). 막별 획득처 일관성 검증은 D5
- 엽전 순환: 2막은 수입 중간, 지출처 최소 (상점 L4/L7 후보뿐, 내기방 없음). 1막에서 번 엽전을 소모품 보충에 쓰는 중계 구간으로 설계한다. 막별 균형 검증은 D5

## 12. M1/M2/M3 의존 항목 (이 문서에서 바뀔 수 있는 것)

- M1 조작 검증 후: 상승 기류와 폭포 역류의 채택 여부와 규격 (상승 높이, 조향감), 벽 점프 샤프트 폭, 물이끼 미끄러짐 채택 여부, 부서지는 징검다리 붕괴/재생 시간. 상승 보조 기믹은 M1 결과에 따라 대체 기믹(고정 발판 증설 등)으로 바뀔 수 있다
- M1/M2: 수중 이동과 수중 전투 상세 규칙 (유영 대시, 수중 공격 제한)
- M2: 용왕 계열 권능의 감전 피해 감소 폭 (권능 구현 시. 용왕은 몸주가 될 수 없으므로 몸주 조건은 폐기), 이벤트 점수 8종과 부여 수의 시드 시뮬레이션 검증
- M3: 2막 구현 전체. 템플릿 소요량 확정, 중간보스 풀 확장 (우선 2종 이후)
- M2 구현 전 결정: 보스전 데스매치 적용 여부 (1막과 공유 미결정)
- 밸런싱 단계: 보상 수치 전부, 감전 지속시간과 재전도 쿨다운, 수위 전환 속도

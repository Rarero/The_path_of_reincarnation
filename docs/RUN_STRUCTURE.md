# 런 구조 설계 (게임 구조)

최종 수정: 2026-08-09 (11장 자유 이동 전환을 1~10장에 반영 정합)
상태: 1차 (구조 확정)
상위 문서: docs/GDD.md 4~5장. 이 문서는 런의 거시 구조(막, 노드, 배치 규칙, 시간 예산)를 정의한다. 방 내부 규격(입구, 출구, 슬롯)은 별도의 방 규격 문서에서 다룬다.

**읽는 순서 주의 (2026-08-09).** 2026-08-06 재개정으로 층 구조와 강제 조우와 관문을 전부 폐기했고, 그 결과는 11장에만 반영돼 있다. 1~10장에는 층 전제 서술이 남아 있으며 코드(scripts/map/run_map.gd)는 11장을 따른다. **충돌하면 11장이 기준이다.** 1~10장의 재작성은 별도 세션 과제로 남긴다.

## 1. 확정 사항 요약

- 경로 구조: 노드 맵 선택형. 막 진입 시 노드 맵을 제시하고 플레이어가 경로를 선택한다. 노드 맵 UI는 가로 배치, 왼쪽에서 오른쪽으로 진행한다
- 중간보스: 고정 개체 없음. 막당 중간보스 고정층 1개를 반드시 거친다 (2026-07-24 변경, 회피 불가). 그 층의 노드는 서로 다른 개체와 전투 유형(순수, 기믹 파훼, 이벤트형)이라, 선택은 "싸우느냐"가 아니라 "어느 중간보스를 어떤 방식으로 상대하느냐"가 된다. 개체는 막별 풀(막당 5~10종 목표)에서 뽑는다
- 보스 직전: 막마다 보스 직전 층을 쉼터 고정층으로 두어 반드시 한 번 휴식한다 (2026-07-24)
- 시간 배분: 점증형. 1막 지도는 노드 34개다 (2026-08-06 재개정, 11.6. 종전 표기 "1막 9층, 2막 10층, 3막 11층"은 폐기된 층 구조다). 목표 런 길이는 40~55분이다 (2026-08-06 재산정, 4장. 종전 30~45분)
- 추가한 층은 전부 선택 노드(신당 또는 이벤트) 층이다 (2026-07-27). 전투로 채우면 조우 하한 문제가 풀리지 않는다. 권능 획득 하한, 대장장이 조우, 내기방 노출 같은 같은 성격의 하한 문제를 개별 보장 규칙으로 하나씩 막는 대신 노드 수로 일괄 해소한다
- 노드 1개 = 방 1개 = 씬(.tscn) 1개. 방 조합식 절차 생성(GDD 5장)의 상위 계층이 노드 맵이다

## 2. 노드 맵 규칙 (공통)

### 구조 (비선형 분기, 슬레이 더 스파이어식)

- 지도는 폭이 넓고 경로가 갈라지고 교차하는 비선형 그래프다 (2026-07-24 결정). 두 줄 고정이 아니라 층마다 여러 노드가 세로로 늘어서고 간선이 교차한다
- 막 = 지도 한 장. 노드 34개를 흩뿌리고 가까운 것끼리 잇는다 (2026-08-06 재개정, 11.2). 층 개념은 없고 난이도는 진행도가 정한다 (11.6.1)
- 노드 맵 UI는 가로 배치. 왼쪽(시작)에서 오른쪽(막 보스)으로 진행한다 (2026-07-24 결정)
- 시작 노드는 첫 자유 지점에서 여러 개 중 하나를 고른다. 진행 방향으로 갈수록 길이 갈리고 다시 합쳐지며 교차한다
- 층 구조를 폐기했다 (2026-08-06 재개정, 11.2). 지도는 흩뿌린 노드의 근접 그래프이고 간선은 전부 양방향이다
- 이동은 한 번에 한 칸이다. 인접 노드로만 간다. 그 외의 제약은 없다. 앞으로도 뒤로도 몇 번이든 갈 수 있다
- 강제로 지나야 하는 노드가 없다. 고정 배리어 층과 관문을 전부 폐기했다
- 맵은 막 진입 시 시드 기반으로 생성한다. 같은 시드는 같은 맵을 재현한다
- 노드 종류는 맵 전체 공개. 선택의 재미는 정보 공개가 전제다
- 핵심 규칙 (2026-08-06 개정): 어디를 밟을지는 플레이어가 정하고, 통제는 경로 제약이 아니라 이동 예산이 한다 (11장). 좋은 노드는 본선에서 벗어난 자리에 두어 들르는 데 대가가 들게 한다 (11.6). 생성기의 경로 점수 검사는 하한 보장으로 축소했다 (10장, 11.9)

### 진행 흐름

방 클리어 → 출구 도달 → 노드 맵 표시 → 인접 노드 선택(전진, 횡보, 후퇴) → 명줄 차감 → 해당 방 씬 로드

- 이미 클리어한 방으로 다시 들어가면 적이 차지 않고 귀문이 즉시 열린다 (11.5 빈 방)

### 배정 규칙

- 첫 층(L1)은 항상 전투방. 워밍업 구간
- 같은 종류의 비전투 노드가 인접 층에 연속 배치되지 않는다 (상점 뒤 상점 금지)
- 중간보스층은 고정층이다. L1~L2와 보스 직전 층에는 두지 않고 막 중반에 배치한다. 해당 층의 모든 노드가 중간보스이며 어떤 경로로도 반드시 1회 거친다
- 보스 직전 층은 쉼터 고정층이다. 모든 경로가 보스 전에 한 번 회복이나 강화를 한다
- 보장 등급 2단계
  - 고정층: 해당 층의 모든 노드가 같은 종류. 어떤 경로로도 반드시 만난다 (전투 L1, 신당, 중간보스, 쉼터)
  - 선택 보장: 해당 층에 그 종류 노드가 최소 1개 존재. 경로 선택으로 획득 여부가 갈린다
- 비밀방(GDD 4장, 9장)은 노드가 아니다. 방 내부의 숨김 통로로 구현하며 노드 맵에 노출되지 않는다

### 중간보스 규칙 (강제 조우, 3유형)

- 중간보스는 회피 불가다. 대신 중간보스 고정층은 서로 다른 개체와 전투 유형의 노드 2~3개로 구성되고, 플레이어가 그중 하나를 고른다 (몸주신 고정층과 같은 선택 구조)
- 전투 유형 3종
  - 순수 전투: 보스의 패턴을 읽고 회피하며 딜을 넣는 정통 전투
  - 기믹 파훼: 방의 오브젝트나 특정 행동으로 기믹을 수행해야 피해가 들어가는 전투
  - 이벤트형: 전투가 아닌 이벤트(달리기, 씨름 등)를 중간보스 난이도로 심화한 형태. 전투 빌드가 약해도 돌파할 여지를 준다
- 스트레스 완화 장치 (강제화 보완, 2026-07-24)
  - 이벤트형 중간보스는 생기 몰림 데스매치 타이머(9장)를 적용하지 않는다
  - 중간보스 노드 진입 시 소회복을 제공한다. 저체력 진입의 벽을 낮춘다
  - 중간보스 직전 층은 회복이나 긍정 노드를 선택 보장으로 배치한다
  - 생성 시 3유형이 순수 전투로만 몰리지 않게 균형을 보장한다 (유형 다양성)
  - 개체 강도 차이는 10장 개체 가감으로 조정하고 풀 평형을 유지한다

### 몸주신 보장

- 첫 신당은 몸주 결정으로 런 정체성을 만든다 (GDD 7장). 1막 L3을 몸주 신당 고정층으로 두어 모든 런에서 몸주 획득을 보장한다
- 몸주 신당은 방 안에서 상시 4계열 중 3종을 랜덤 제시하고 하나를 고르게 한다 (2026-07-25 변경). 노드별로 다른 신을 배정하던 이전 규칙은 폐기했다. 어느 노드로 들어가도 같은 선택 구조를 만난다
- 그 이후의 신당은 권능 3택이다. 액티브는 나오지 않는다 (docs/systems/BOONS.md 7장)

## 3. 막별 구성

아래 배정표 읽는 법 (2026-07-24 비선형 구조 반영): 각 층의 "배정"은 그 층에 나올 수 있는 종류다. 고정 배리어 층(단일 종류로 표기: 전투 L1, 신당, 중간보스, 쉼터)은 폭 전체가 그 종류이고 모든 경로가 지난다. 여러 종류가 적힌 자유 층은 그 종류들을 가중 풀로 삼아 폭 2~5 노드로 채운다. 폭과 간선은 시드 경로 그리기로 생성하며(7장), 표는 종류 구성만 정의한다.

- 내기방은 L4, L6에 노출 후보로만 배치 (선택 보장 아님). 1막 한정 콘텐츠. 씨름 장사 등 중간보스 개체가 내기 상대로 재등장하는 추가 조우 후보 (D2 확정)
- 보물은 기본 배정표에 없다. 희귀 풀 노드와 비밀방으로 등장한다 (변동성 통제, 10장)

### 막 사이 휴식점 (고정)

- 나루 관문(1막 → 2막), 지옥문(2막 → 3막)
- 회복과 강화 중 선택 (GDD 4장 유지). 수치는 밸런싱 단계에서 확정

- 하한 개선 (2026-07-27): 구 구조의 최악 경로는 신당 1 + 중간보스 0(전부 상급 무기 선택) + 보스 3 = 4개였고, 몸주 액티브를 빼면 권능 3개라 조합이 0~1회밖에 안 돌았다. 신당 보장이 6회로 오르면서 최악 경로에서도 권능 8개 이상이 들어와 조합 시스템이 반드시 작동한다. 중간보스 권능 강제나 개별 보장 규칙 추가 없이 노드 수로 해소했다 (docs/DECISIONS.md 결정 21)
- 이벤트형 중간보스는 전투 보상 대신 이벤트 성격의 보상(엽전, 소모품, 상급 무기 등)으로 대체할 수 있다. 권능 획득 기대는 유형 균형 보장으로 유지한다
- 일반 신당 3택에 몸주 계열이 최소 1개 포함되게 가중치를 준다. 몸주신 계열 권능이 손에 들어와야 같은 계열끼리의 조합(공수)이 성립한다 (docs/systems/BOONS.md 5장, 7장. 2026-07-25 골격 개정으로 계열 3개 축적 해금 규칙은 폐기됐다)
- 여의주 조각(메타 재화)은 보스 확정 드랍 + 비밀방과 도전방 추가 획득
- 런당 유물 기대 획득: 3~7개 (2026-07-25 신설, 상세는 docs/systems/RELICS.md). 유물은 노드 종류가 아니라 위 보상 소스의 내용물로 들어가므로 10장의 종류별 점수표와 막 기준치는 변경하지 않는다. 상점 +30과 보물 +60에 유물 가치가 이미 흡수되어 있다고 본다
- 권능 상세(보유 구조, 티어와 조합, 등급, 신당 3택 알고리즘, 계열별 풀)는 docs/systems/BOONS.md. 권능 보유 상한은 액티브 1 + 권능 3이며, 획득 10~13개의 대부분은 조합 재료가 된다 (2026-07-25 골격 개정, 2026-07-27 각 막 +1층 상향)

## 7. 구현 방침 (Godot)

- 맵 데이터: 순수 GDScript 자료구조 (RefCounted 기반 RunMap, 층 배열과 간선 목록). 씬과 분리해 gdUnit4 단위 테스트 가능하게 유지한다. 생성 규칙(보장, 연속 금지, 중간보스 고정층, 보스 직전 쉼터 고정층, 경로 예산)은 전부 테스트로 고정한다
- 생성 절차 (슬레이 더 스파이어식 경로 그리기)
  1. 골격 생성: 폭 격자(층 x 열) 위에 시드 경로 N개(초안 6)를 왼쪽 끝에서 오른쪽 끝까지 그린다. 각 경로는 다음 층에서 인접 열(현재 열 ±1)로 이동하며 지나간 노드와 간선을 활성화한다. 경로들의 합집합이 분기와 교차가 있는 DAG가 된다
  2. 고정 배리어 층 지정: 전투 L1, 신당, 중간보스, 보스 직전 쉼터 층은 활성 노드 전부를 그 종류로 채운다
  3. 자유 층 배정: 나머지 층의 활성 노드를 배정표 가중 풀에서 뽑아 채운다 (연속 금지 등 제약 검사)
  4. 콘텐츠 선택: 중간보스 개체와 유형, 이벤트 P/N을 시드로 확정한다
  5. 검증: 보장 충족, 연속 금지, 경로 점수 예산(10장). 실패 시 재배정
- 검증으로 확인 (2026-07-24): 위 방식으로 1막(8층, 폭 3~4, 경로 49개)을 생성해 전 경로가 예산 안에 들었다. 폭이 넓을수록 균형 잡을 여지가 많아 예산 충족이 쉬워진다
- 이 검증은 무효다 (2026-07-27). 이벤트 기본 0에 8/9/10층 배정표 기준이었다. 이벤트 실점수 반영과 9/10/11층 개정 후 재검증이 필요하다. **1막 49경로(폭 3~4) 예산 재검증은 M2 시드 시뮬레이션의 첫 번째 항목이다** (2026-08-05 D6 재확인). 재검증은 10장 테스트 규칙 3(예산 준수, 시드 1000개)과 규칙 8(기준치 회귀, B=+25 / W=75)로 고정하며, 통과 전에는 어떤 경로 예산 수치도 확정으로 보지 않는다
- 시드: 런 시드에서 막별 서브 시드 파생. 재현 가능해야 디버깅과 테스트가 된다
- 맵 UI: CanvasLayer 오버레이. M2에서는 아이콘과 선 연결 수준의 최소 구현
- 방 전환: 노드 선택 시 해당 방 씬 로드. 방 규격(입출구 연결)은 방 규격 문서에서 정의 (프로토타입 단계 작성 예정)

- M2 수직 슬라이스: 1막 9층 + 1막 보스(문얼굴/방망이 랜덤), 노드 맵 최소 UI(가로, 비선형 분기), 방 템플릿 19개, 신 계열 2종, 1막 중간보스 2~3종(강제 조우이므로 최소 2종 필수, 유형은 순수 + 기믹 또는 이벤트형 혼합). 노드 맵 UI는 폭이 넓은 분기 그래프를 그리는 수준으로 시작
- M3 알파: 2막, 3막 확장. 시왕의 시험과 뇌물 이벤트는 M3에서 착수 (3막 콘텐츠). 중간보스 풀을 막당 5~10종 목표로 확장

## 9. 방당 시간 압박 규칙 (생기 몰림, 가칭)

전투가 루즈해져 시간 예산을 넘는 것을 막는 소프트 타이머. 사망 벌칙이 아니라 전투를 끝내는 가속 장치다.

### 기본 규칙 (전 전투방, 순수/기믹 중간보스 포함)

- 방마다 최대 전투 시간을 둔다. 초과 시 적과 플레이어의 공격력이 함께 상승한다 (데스매치)
- 적의 상승률이 플레이어보다 가파르고, 양쪽 모두 상한이 있다. 버티기로 이득을 보는 악용을 차단한다
- 타이머는 전투 상태(적 생존 중)에만 진행한다. 클리어 후 탐색(비밀방 등)은 압박 없음
- 발동 전 경고 연출을 준다. 발동은 실패가 아니라 분위기 전환으로 표현한다
- 이벤트형 중간보스 제외 (2026-07-24): 달리기, 씨름 등 이벤트형 중간보스에는 데스매치 타이머를 적용하지 않는다. 중간보스가 강제 조우가 된 만큼, 압박 중첩을 피하고 유형별 성격을 살린다

### 서사적 당위성

- 근거: 산 자의 생기를 저승 존재가 탐한다 (GDD 2장). 산 자가 한자리에 오래 머물면 생기가 고여 퍼지고, 그 기운에 주변 존재가 광폭화한다
- 막별 연출: 1막 도깨비불이 붉게 변함, 2막 물이 끓어오름, 3막 옥졸과 형리의 눈이 뒤집힘

### 시간 보상 (격리 적용)

- 제한시간 내 클리어 시 상급 보상 방식은 전 전투방에 적용하지 않는다. 고DPS 빌드만 우대해 빌드 다양성(핵심 재미)과 충돌하기 때문
- 적용처는 두 곳으로 격리: 내기방(엽전을 걸고 제한시간 클리어 내기), 시왕의 시험(3막 도전방의 시험 유형 중 하나)
- 시간 도전은 항상 플레이어가 선택해서 진입한다

### 수치 확정 시점

- 발동 시간, 상승률, 상한은 M1 전투 프로토타입 체감 확인 후 확정한다. M1 검증 항목에 포함
- 발동 시간은 방 시간 예산에 연동한다 (2026-07-27 결정). 일반 전투방은 위협 포인트 예산에 따라 6pt 이하 90초, 8pt 이상 110초다 (docs/act1/ENEMIES.md 2장). 순수와 기믹 중간보스는 중간보스 시간 예산(120초 기준, 범위 90~150)의 상단인 150초다 (docs/act1/MIDBOSS.md 1장). 이벤트형 중간보스는 제외(위 규칙)이고, 보스전은 별도 데스매치 타이머를 두지 않고 광폭 페이즈로 대체한다 (2026-08-05 D6, docs/act1/BOSS.md 1장). 상승률과 상한 곡선은 M1 전투 프로토타입에서 확정한다

## 10. 노드 맵 밸런스 점수제 (내부 검증)

상태: 역할 축소 (2026-08-06). 이동 예산(11장) 도입으로 이 장의 점수는 플레이어에게 노출되지 않는 생성기 내부 검증 도구가 됐다. 상한 검사는 폐지하고 하한 검사만 남기며, 검사 대상은 최단 완주 경로로 한정한다. 자세한 것은 11.9. 아래 점수표와 절차는 그 축소된 역할 안에서 유효하다. 수치는 전부 초안이고 구현은 M2 RunMap 생성기에서 수행한다 (7장).

### 목적과 원칙

- 무작위 배정이 만드는 경로별 경험 편차를 경로 단위 점수 예산으로 통제한다
- 도전의식보다 재미가 최우선. 좋은 경험을 많이 주는 것이 목표다
- 개별 보정 금지: 좋은 보상을 얻었다고 나쁜 이벤트를 강제로 붙이지 않는다. 통제는 경로 합계로만 한다
- 운 좋은 런 인정: 예산 상한에 가까운 경로의 경험도 게임의 재미로 인정한다

### 점수 체계: 순점수, 2계층

- 모든 노드에 순점수를 부여한다. 순점수 = 위험과 부담에서 보상을 상쇄한 경험 순가치 (2026-07-24 결정). 점수는 난이도가 아니라 경험 순가치다. 난이도 상승(3막 전투 밀도 등)은 점수가 아니라 전투 밀도와 개체 가감이 담당한다
- N 등급(마이너스), P 등급(플러스), 중립(0)으로 구분한다
- 고정층은 상수다 (2026-07-24): 중간보스가 강제 조우 고정층이 되면서 모든 경로에 같은 점수로 들어간다. 전투 L1, 신당, 보스 직전 쉼터도 마찬가지다. 고정층 점수는 기준치 B에 흡수되고 경로 간 변동성에 기여하지 않는다. 변동성은 자유 선택 층에서만 나온다
- 리스크/리턴 노드(내기방, 시왕의 시험, 뇌물)는 위험만 반영하지 않는다. 순점수는 예산이 플레이어의 위험 선택을 왜곡하지 않게 한다
- 점수는 2계층이다 (2026-07-24 확장): 노드 점수 = 종류 기본 점수 + 개별 콘텐츠 가감. 아래 점수표는 종류 기본값이고, 중간보스 개체나 이벤트처럼 난이도 편차가 있는 콘텐츠는 개별 가감을 더한다. 가감 규칙은 아래 "개별 콘텐츠 점수 가감" 참조

### 종류별 기본 점수표 (초안)

| 종류 | 등급 | 점수 | 산정 근거 (위험/부담 대비 보상) |
|---|---|---|---|
| 전투 | N | -20 | 부담 -30, 엽전과 드랍 +10 |
| 이벤트 | 중립 | 0 (P/N 확정) | 노드 진입 시 P 또는 N으로 확정. 기본 0, 실제 값은 콘텐츠 P/N (아래) |
| 중간보스 | N | -40 | 부담 -100, 권능 3택1 또는 상급 무기 +60. 고정층(강제) |
| 시왕의 시험 | N | -20 | 도전 부담 -60, 조건부 보상 +40. 선택 진입 |
| 내기방 | 중립 | 0 | 도박 기대값을 중립으로 설계 |
| 뇌물 이벤트 | 중립 | 0 | 엽전 지불로 전투 회피와 보상. 경제 교환 |
| 상점 | P | +30 | 획득 기회, 엽전 지출 필요 |
| 신당 | P | +40 | 권능 확정 획득 |
| 쉼터 | P | +40 | 회복 또는 강화. 보스 직전 고정 |
| 보물 | P | +60 | 무상 획득. 희귀 풀 노드 (기본 배정표 밖) |

- 이벤트 노드 (2026-07-24 신설, 기존 플랫포밍 노드 대체): 노드 맵에 "이벤트"로 표기하고 P 또는 N으로 확정되는 노드다. P/N 발생 확률을 노드 맵에 표시한다 (예: 좋음 60 / 나쁨 40). 기본 점수는 0(중립)이고 실제 점수는 확정된 P/N 값이며 생성 시 시드로 정해진다. P/N 내용 목록과 값은 D2~D4에서 지정한다 (긍정 +10~+30, 부정 -10~-30. 2026-07-27 축소, 옛 범위 ±40). 큰 값 이벤트(±30)는 막당 소수로 제한해 변동성을 통제한다
- 보스와 막 사이 휴식점은 노드 맵 밖의 전 경로 공통 구간이라 점수 대상이 아니다. 막 보스와 염라의 난이도 조정은 점수제 밖(밸런싱)에서 다룬다. 비밀방은 노드가 아니므로 제외한다 (2장)
- 점수는 초안이다. D2~D4의 개별 점수 지정과 M2 시드 시뮬레이션 후 조정한다. 유물 등 콘텐츠가 늘면 재조정한다

### 개별 콘텐츠 점수 가감

종류 기본 점수 위에 콘텐츠 단위의 난이도 가감을 얹는 계층이다. 중간보스 풀의 개체별 강도 차이, 이벤트별 경중, 향후 추가 콘텐츠의 난이도를 점수에 반영한다.

- 노드 점수 = 종류 기본 점수 + 개별 가감. 가감의 기본값은 0
- 가감 대상: 중간보스 풀의 각 개체 (강한 개체 마이너스 가감, 약한 개체 플러스 가감), 향후 유물 이벤트 등 신규 콘텐츠
- 이벤트 노드 방식 (2026-07-24 변경): 이벤트는 전용 노드 종류다 (기존 전투방 부여 수식 방식 폐기). 노드 진입 시 P 또는 N으로 확정되며 확률을 표시한다. 이벤트 노드의 P/N 값은 기준치 계산에서 기본 0으로 잡고, 실제 확정 값은 경로 예산 검사(실점수)에 포함한다. 값 크기는 ±10~30이며 큰 값은 막당 소수로 제한해 변동성을 통제한다 (2026-07-27 축소. 옛 범위 ±40에서는 1막 자유 층 4개의 이론 최대가 +110으로 허용 폭을 크게 벗어났다. 산술 검증은 docs/act1/EVENTS.md 6장). D2~D4의 기존 이벤트 목록과 점수는 이벤트 노드의 P/N 콘텐츠로 이관한다
- 가감 한도 (초안): 절대값 20 이내, 그리고 종류 기본 점수의 부호를 바꾸지 않는다. 예: 중간보스 개체는 -40 기준 -60 ~ -20. 한도를 넘는 난이도의 콘텐츠는 가감이 아니라 별도 종류로 분리해 기본 점수를 새로 정한다
- 풀 평형 규칙: 같은 풀(예: 1막 중간보스 풀) 안에서 개별 가감의 합은 0에 맞춘다 (허용 오차 ±5). 풀 전체가 무겁거나 가벼우면 가감이 아니라 종류 기본 점수를 조정한다. 이 규칙으로 종류 기본 점수 기반의 막 기준치가 유효하게 유지된다
- 확정 시점: 점수 가감이 있는 콘텐츠 선택(중간보스 개체, 이벤트 내용)은 맵 생성 시 시드로 확정하고, 경로 점수 검사는 가감이 반영된 실제 점수로 수행한다. 방 로드 시점의 랜덤은 점수와 무관한 요소(내부 슬롯 배치 등)만 허용한다
- 데이터 위치: 점수는 코드 상수가 아니라 콘텐츠 정의 데이터(중간보스 개체 리소스, 이벤트 정의)에 둔다. 종류 기본값 테이블과 개별 가감 필드를 분리해 콘텐츠 추가 시 코드 수정 없이 확장한다
- 노드 종류는 맵 전체 공개(2장)가 원칙이다. D2 검토 결과 (2026-07-24): 이벤트는 부여 여부와 극성(P/N) 표식만 공개하고 내용은 비공개, 중간보스는 개체를 비공개한다 (풀 랜덤의 긴장 유지)

### 예산 규칙: 막 기준치 상대 편차

- 단일 절대 범위(-50 ~ +50) 대신 막 기준치 상대 편차를 쓴다 (2026-07-24 결정). 막별 전투 밀도가 다르므로(3막 정체성이 전투 밀도) 절대 범위는 전 막 공통으로 성립하지 않는다
- 막 기준치 B = 배정표(3장)의 층별 후보 점수 평균의 합. 설계 상수로 이 문서에 고정한다
- 허용 폭 W는 자유 층 수에 연동한다 (2026-07-27 개정). W = 자유 층 수 x 15
  - 고정 폭 ±50은 자유 층 4개 기준으로 정한 값이었다. 변동성은 자유 층에서만 나오므로 자유 층이 늘면 이론 스윙이 함께 커진다. 고정 폭을 유지하면 층 구성을 조정할 때마다 폴백 발생률이 예측 불가하게 변한다
  - 자유 층당 15는 구 값(1막 자유 4개에 ±50, 층당 12.5)보다 약간 느슨하다. 층이 늘면서 극값 경로 회피 부담이 커진 것을 반영했다
  - 배정표를 수정하면 W도 자동으로 따라간다. 테스트 규칙 8이 기준치와 함께 W도 검사한다
- 예산 규칙: 시작 노드부터 막 보스 직전까지 모든 완주 경로의 합계가 B-W ~ B+W 안에 들어야 한다
- 현행 배정표(9/10/11층) 기준 막 기준치 (2026-07-27 재계산, 이벤트 노드 기본 0)

| 막 | 층 | 고정층 | 자유층 | 기준치 B | 허용 폭 W | 허용 범위 |
|---|---|---|---|---|---|---|
| 1막 | 9 | 4 (L1, L3, L5, L9) | 5 | +25 | 75 | -50 ~ +100 |
| 2막 | 10 | 3 (L1, L5, L10) | 7 | 0 | 105 | -105 ~ +105 |
| 3막 | 11 | 4 (L1, L4, L5, L11) | 7 | +5 | 105 | -100 ~ +110 |

- 산출 근거 (층별 후보 점수 평균의 합)
  - 1막: -20, -10, +40, -10, -40, +15, +20, -10, +40 = +25
  - 2막: -20, -10, -10, +35, -40, -10, +20, -10, +5, +40 = 0
  - 3막: -20, -10, -20, +40, -40, +20, -10, -20, -10, +35, +40 = +5
- 각 막 +1층으로 기준치가 전부 올랐다 (구 값 1막 +5, 2막 -20, 3막 -15). 추가한 층이 전부 선택 노드 층(신당 +40 또는 이벤트 0)이라 경험 순가치가 오른 것이며 의도한 결과다
- 난이도 점증은 점수가 아니라 전투 밀도와 중간보스 개체 가감이 담당한다. 3막이 2막보다 B가 높은 것은 쉼터가 2개라 그렇고, 실제 난이도는 3막이 높다
- 자유 층이 늘어 이론 경로 스윙도 커졌다. 특히 1막 L7은 신당(+40)과 이벤트(-30)로 갈려 한 층에서 70점 차가 난다. 허용 폭을 자유 층 수에 연동한 것이 이 문제에 대한 답이다
- 변동성은 자유 층에서만 나온다: 중간보스와 쉼터 등 고정층은 모든 경로에 같은 상수라 B에 흡수되고 변동성에 기여하지 않는다. 허용 창은 자유 층 선택의 편차를 담는 것이므로 자유 층 수에 비례해야 한다. 변동성 통제를 위해 큰 스윙 노드(보물 +60)는 기본 배정표에서 빼 희귀 풀로 두고, 이벤트 값은 완만히(±10~30) 두며 큰 값은 소수로 제한한다
- 2막과 3막은 자유 층이 7개라 허용 폭이 105로 넓다. 폴백은 줄지만 경로 간 경험 격차가 커질 수 있다. M2 시드 시뮬레이션에서 폴백 발생률뿐 아니라 실제 경로 점수 분포의 표준편차도 함께 측정해, 자유 층당 15가 적정한지 판정한다
- 기준치는 종류 기본 점수로만 계산한다. 개별 가감과 이벤트 P/N은 기준치에 넣지 않는다 (실점수 검사에만 반영)
- 배정표를 수정하면 기준치 B와 허용 폭 W를 재계산해 이 표를 갱신한다 (테스트 규칙 8이 누락을 감지)

### 생성 절차 통합

7장 절차(골격 생성 → 종류 배정 → 검증 → 재배정)의 검증 단계에 점수 검사를 마지막 검사로 넣는다.

검증 순서:

1. 보장 검사: 고정층(전투 L1, 신당, 중간보스, 보스 직전 쉼터), 선택 보장
2. 배치 규칙 검사: 연속 금지, 중간보스 고정층 위치(L1~L2와 보스 직전 제외), 중간보스 유형 균형
3. 경로 점수 검사: min/max 경로 합이 허용 범위 안인지 (이벤트 P/N과 개체 가감 반영한 실점수)

재배정 전략:

- 부분 재배정 우선: 예산 위반 시 극값 경로 위의 변동 노드(고정층과 보장 노드 제외) 1개를 그 층의 배정 후보 내 다른 종류로 교체하고 재검증한다. 시드 결정적으로 수행한다
- 부분 재배정 상한(초안 20회) 초과 시 전체 재배정. 전체 재배정 상한(초안 10회) 초과 시 예산 완화 폴백으로 넘어간다

### 보장 규칙과의 우선순위

충돌 시 아래 순서를 따른다. 위가 우선한다.

1. 고정층 (전투 L1, 신당 몸주신, 중간보스, 보스 직전 쉼터, 3막 중반 쉼터)
2. 중간보스 유형 균형 (순수/기믹/이벤트형이 순수로만 몰리지 않게)
3. 선택 보장 (상점, 신당, 중간보스 직전 회복/긍정)
4. 연속 금지
5. 점수 예산

- 점수 예산이 최하위다. 충돌하면 예산이 물러난다. 보장 규칙은 어떤 경우에도 완화하지 않는다
- 예산 완화 폴백: 허용 폭을 W → W x 1.3 → W x 1.6으로 단계 확장한다 (2026-07-27, 고정 증분에서 배율로 변경). 확장 발생은 로그로 남기고 테스트에서 발생 비율을 감시한다 (초안 상한 5%)
- 중간보스는 강제 조우라 모든 경로에 같은 상수로 들어간다. 경로 간 차이를 만드는 것은 어느 개체와 유형을 고르느냐이며, 개체 가감(풀 평형 합 0)은 경로 예산에 큰 편차를 주지 않는다

### 경로 검사 방식

- 경로 수: 폭을 넓히면(자유 층 2~5, 최대 10층) 경로 수가 늘지만 간선 제약으로 실제 수십~수천 수준이다 (검증 예: 1막 폭 3~4에서 49개). 폭이 커져도 DP 검증 비용은 변하지 않는다
- 채택: 런타임 검증은 DAG 동적 계획법으로 min/max 경로 합만 계산한다. 층 순서대로 노드별 최소/최대 도달 합을 갱신하면 O(노드+간선)로 끝나며 모든 경로 열거가 필요 없다. min ≥ B-W, max ≤ B+W이면 통과. 폭 확장의 핵심 이점은 DP가 경로 수와 무관하게 선형이라는 점이다
- 전수 열거는 테스트와 디버그 도구에서 DP 결과 교차 검증용으로만 사용한다

### gdUnit4 테스트 규칙 (M2 구현 시 고정)

1. 점수표 완전성: 배정표의 모든 노드 종류에 점수가 정의되어 있다
2. 재현성: 같은 시드는 같은 맵과 같은 경로 점수를 만든다
3. 예산 준수: 시드 1000개 생성, 전 막의 모든 경로 합이 허용 범위(B±W) 안이다
4. 완화 비율: 예산 완화 폴백 발생 비율이 상한(초안 5%) 이하다
5. 보장 불변: 부분 재배정 후에도 고정층(전투 L1, 신당, 중간보스, 보스 직전 쉼터), 선택 보장, 연속 금지가 유지된다
6. 검증기 일치: DP min/max와 전수 열거 결과가 일치한다
7. 종료 보장: 부분 재배정과 전체 재배정 루프가 상한 안에 종료한다
8. 기준치 회귀: 문서의 막 기준치 B와 허용 폭 W가 배정표에서 재계산한 값과 일치한다 (W = 자유 층 수 x 15)
9. 콘텐츠 점수 완전성: 풀에 등록된 모든 중간보스 개체와 이벤트 P/N에 점수(기본 + 가감)가 정의되어 있다
10. 가감 한도: 모든 개별 가감이 한도(절대값 20) 안이고 종류 기본 점수의 부호를 바꾸지 않는다
11. 풀 평형: 풀별 개별 가감의 합이 0이다 (허용 오차 ±5). 이벤트 P/N 풀은 이 규칙의 대상에서 제외한다. 이벤트의 변동성은 등급 배정과 경로 예산 검사가 통제한다 (docs/act1/EVENTS.md 6장)
12. 실점수 검사: 경로 점수 검사가 이벤트 P/N과 개체 가감을 반영한 실제 점수로 수행된다
13. 중간보스 강제 조우: 모든 경로가 중간보스 고정층을 정확히 1회 지난다
14. 보스 직전 휴식: 모든 경로가 보스 직전 쉼터 고정층을 지난다
15. 중간보스 유형 균형: 중간보스 고정층에 순수 전투만 배치되지 않고 기믹 또는 이벤트형이 섞인다
16. 비선형 폭: 자유 층의 활성 노드가 최소 폭(초안 3) 이상이고, 시작 노드가 2개 이상이다
17. 연결성: 모든 시작 노드에서 막 보스까지 경로가 존재하고, 고립 노드(진입 또는 진출 간선 없음)가 없다
18. 분기 교차: 간선 교차와 재합류가 존재해 두 줄 고정 형태가 아니다 (경로 다양성 하한 검사)

## 11. 이동 예산 (명줄)

상태: 설계 확정, 수치는 전부 초안. 구현은 M2 RunMap 생성기와 노드 맵 UI에서 수행한다.

2026-08-06 도입. 층을 한 방향으로 훑는 구조에서, 지도를 한 칸씩 자유롭게 오가되 이동 자원이 소모되는 구조로 바꾼다. 어느 방을 밟을지는 플레이어가 정하고, 통제는 경로 제약이 아니라 자원 예산이 한다.

### 11.1 자원 정의

- 이름은 명줄이다. 주인공은 명부에 없는 자이고 수명부 정정이 목표다 (GDD 2장). 저승을 걸어 다니는 동안 명줄이 닳는다는 설정이 이동 소모의 당위성이 된다
- 방 안의 시간 압박인 생기 몰림(9장)과는 다른 자원이다. 생기 몰림은 한 방에 머문 시간, 명줄은 지도 위에서 움직인 거리를 잰다. 문서와 UI에서 두 이름을 섞지 않는다
- 노잣돈(엽전)은 화폐이고 명줄은 이동 자원이다. 서로 교환하지 않는다. 교환을 허용하면 상점이 이동 자원 판매소가 되어 경제 정체성과 이동 설계가 함께 흐려진다
- 명줄은 막마다 초기화한다. 지도 하나가 예산 하나다. 막 사이 휴식점에서 회복된다
- 완주 후 남은 명줄은 소멸한다. 다음 막이나 보상으로 전환하지 않는다. 전환하면 아끼는 것이 최적해가 되어 탐색을 유도하려는 설계 의도와 정반대로 간다

### 11.2 지도 구조 (2026-08-06 재개정: 층 폐기)

층을 버렸다. 1차 설계는 층을 유지한 채 횡보와 후퇴만 열었는데, 그것도 이동 제약이다. "총 예산만 지키면 이동에 제약을 두지 않는다"는 원안과 어긋나 다시 짰다.

- 지도는 296 x 176 영역에 흩뿌린 노드 22~32개의 근접 그래프다. 층도 행도 없다
- 노드끼리 최소 32px 간격을 두고, 46px 안의 가까운 노드와 최대 4개까지 잇는다.
  32px는 지도 기호(16px)와 테두리(반경 11)가 서로 닿지 않는 값이다 (2026-08-06)
- **길끼리 교차하지 않는다 (평면 그래프, 2026-08-10).** 짧은 후보부터 넣되, 이미 놓인 길과 가로지르거나 다른 노드를 12px 안쪽으로 스치는 후보는 버린다.
  종전에는 노드마다 가까운 넷을 그냥 집어서 길이 X자로 만났다. 그 자리에 갈림길이 없는데 두 길이 겹쳐 보이는 것은 이치에 맞지 않고, 실제로 갈 수 없는 이동으로 읽힌다.
  결과로 평균 차수가 2.7, 간선이 34개다 (종전 45개). 최단/예산 67퍼센트로 변화가 없고, 보스 차수는 7.1에서 4.5로 내려가 더 자연스럽다
- **모든 간선은 양방향이다.** 앞으로도 뒤로도, 몇 번이든 갈 수 있다
- **강제로 지나야 하는 노드가 없다.** 고정 배리어 층, 관문, 일방통행을 전부 폐기했다. 중간보스도 신당도 쉼터도 지도 위의 노드일 뿐이다
- 시작 노드는 왼쪽 끝, 보스는 오른쪽 끝에 고정한다. 나머지는 자유 배치다
- 흩뿌리기로 끊긴 덩어리가 생기면 가장 가까운 본체 노드에 이어 붙여 전 노드 도달을 보장한다
- **보스 접근 부채 (2026-08-09).** 진행도 0.70 이상인 노드는 거리와 간선 상한을 무시하고 보스와 직접 잇는다. 2026-08-10 평면 규칙이 우선하도록 고쳤다. 짧은 것부터 넣고 교차하는 것은 버리므로 직결 비율은 64퍼센트지만, 후반 노드의 보스 우회배율은 1.04(최악 3.8)로 종전 1.55(최악 13.2)보다 훨씬 낫다. 근접 연결만 쓰면 보스 차수가 평균 1.7이라, 보스 코앞 노드도 지도를 크게 우회해야 들어갈 수 있었다. 마지막 구간에서만 이동이 사실상 강제되는 셈이라 자유 이동 원칙에 어긋난다

**지형 틀 (2026-08-09).** 흩뿌리기가 사각형 안 균질 난수 하나뿐이라 어떤 시드든 "고르게 퍼진 점 무리" 한 가지 모양만 나왔다. 흩뿌릴 수 있는 영역의 모양을 다섯 가지로 나눈다. 틀은 원본 시드로만 정하므로 재생성이 걸려도 바뀌지 않는다.

| 틀 | 영역 | 목표 / 실측 노드 | 생기는 성질 |
|---|---|---|---|
| 광장 | 전 영역 (종전과 같음) | 30 / 29.9 | 어디로든 갈 수 있다. 선택지가 가장 많다 |
| 갈래 | 가운데 가로 띠(22~32px)를 비움 | 26 / 26.1 | 위아래 두 갈래가 시작과 보스에서만 만난다. 초반에 한쪽을 고르면 되돌리는 값이 비싸다 |
| 사슬 | x를 5~7칸으로 갈라 홀수 칸은 중앙 ±14~20px만 허용 | 27 / 26.9 | 넓은 방과 좁은 통로가 번갈아 온다. 통로가 병목이라 경로가 수렴한다 |
| 성단 | 세로로 긴 타원 3개(가로 반지름 32~40px, 세로 70px) 안에만 허용 | 26 / 24.1 | 뭉치 안은 촘촘하고 뭉치 사이는 빈 세로 띠다. 건너는 간선이 비싸 이동비가 계단식으로 튄다 |
| 활꼴 | 띠 중심이 sin 곡선으로 ±42px 휨, 반두께 40px | 24 / 20.9 | 지도 전체가 위나 아래로 굽는다. 직진이 곧 최단이 아니다 |

- 목표 노드 수에 -2~+2를 더해 같은 틀 안에서도 규모가 갈린다. 실측은 18~32개다
- 최소 간격 32px가 절대 상한이라, 영역을 깎는 틀일수록 실제 노드가 적게 들어간다. 그래서 목표를 틀마다 따로 잡았다. 성단과 활꼴은 목표에 못 미치는데, 그 미달 자체가 규모 차이를 만들어 그대로 둔다
- 노드가 18개(NODE_FLOOR) 미만이면 시드를 파생해 다시 그린다
- 성단의 뭉치를 원이 아니라 세로 타원으로 잡은 이유는, 원으로 하면 반지름이 뭉치 간격의 절반을 넘어 서로 겹쳐 버려 뭉치로 읽히지 않기 때문이다

폐기한 규칙 (2026-08-06)

- 고정 배리어 층 (전투 L1, 신당 L3, 중간보스 L5, 쉼터 L9): 강제 통과는 이동 제약이다. 보장이 필요하면 통제가 아니라 배치와 유인으로 한다
- 관문 (일방통행): 되돌아가기를 막는 장치다
- 곁가지 교차 배치로 전투를 강제하던 규칙: 전투 비중은 지도 구성비로 잡는다
- 층당 노드 1개 방문, 경로당 방문 방 수 = 층 수

### 11.3 이동 비용

비용은 지도상 거리에 정비례한다. 지도에서 선이 길면 비싸다는 규칙이 눈으로 읽혀 설명이 필요 없다.

- 비용 = max(1, round(두 노드 사이 거리 / 9))
- 최소 간격이 32px이라 가장 짧은 이동은 4 (2026-08-10 정정: run_map.gd MIN_SEPARATION), 가장 긴 이동(46px)은 5다
- 방향 계수, 후퇴 배수, 횡보 구분이 없다. 뒤로 가는 이동도 앞으로 가는 이동과 같은 값이다

- 이미 클리어한 방은 빈 방이 된다. 적이 다시 차지 않고 통과만 된다 (체류 8초). 상점은 재고가 남아 있으면 다시 이용할 수 있고, 신당과 이벤트와 쉼터는 1회성이다

### 11.6 노드 구성과 배치

이동을 통제하지 않으므로 통제 수단은 구성비와 배치뿐이다.

종류 구성은 2026-08-09부터 고정 개수가 아니라 범위다. 매 런 노선 선택이 달라지게 하려는 것이다.

| 종류 | 범위 | 측정 평균 | 비고 |
|---|---|---|---|
| 전투 | 남는 자리 전부 | 14.8 (지도의 58퍼센트) | 시작 노드 포함 |
| 이벤트 | 2~5 | 3.2 | |
| 신당 | 1~3 | 1.7 | 몸주와 권능 |
| 상점 | 1~3 | 1.7 | |
| 중간보스 | 1~3 | 1.7 | 강제 조우 폐기. 잡을지 피할지 고른다 |
| 내기방 | 0~2 | 1.0 | 없는 런이 있다 |
| 쉼터 | 0~2 | 1.0 | 없는 런이 있다 |
| 보스 | 1 | | 오른쪽 끝 고정 |

뽑는 절차

1. 종류마다 하한을 먼저 깐다 (합 5)
2. 비전투 목표 수를 8~14에서 뽑는다
3. 상한이 남은 종류에 무작위로 하나씩 얹어 목표에 닿는다
4. 전투가 남는 자리를 전부 가져간다

- 전투 하한이 목표 수보다 세다. 전투가 지도의 50퍼센트(COMBAT_SHARE_MIN) 아래로 내려가면 비전투 목표를 깎는다. 노드가 적은 틀에서 이 규칙이 작동한다
- 전투 비중은 층 구조 시절 방문 방의 35퍼센트뿐이었고 이벤트와 신당이 과했다 (2026-08-06 지적). 지금은 53~72퍼센트 사이에서 런마다 갈린다
- 보상 노드(신당, 상점, 내기, 쉼터, 중간보스)는 지도 가로 중앙축에서 먼 자리에 배치한다. 보상 노드의 축 이탈 거리가 전투보다 평균 40px 크고, 시드 600개 전부에서 우위가 유지된다. 직진하면 전투만 하고, 보상을 얻으려면 예산을 쓴다
- 강제 통과가 없어져 몸주 신당과 중간보스 조우가 보장되지 않는다. 유인으로 대체한다. 신당은 초반 접근성이 좋은 자리에 두고, 중간보스는 보상을 크게 잡아 잡을 이유를 만든다. 이 두 항목은 M2 플레이 판정에서 재확인한다

### 11.6.1 난이도 점증

층이 없으므로 방 위협 예산은 진행도가 정한다.

- 진행도 = 시작에서 보스까지의 가로 위치 비율 (0~1)
- 방 위협 예산 = 3pt에서 10pt까지 진행도로 보간, 고갈 단계를 더한다
- 초반에 지도 오른쪽으로 질러가면 그만큼 방이 세다. 자유 이동과 위험의 교환이 위치 하나로 표현된다

### 11.7 예산 소진과 노드 맵 UI

명줄이 0 이하로 내려가도 이동은 막지 않는다. 이동 불가는 게임을 세우고, 즉사는 탐색을 유도하려는 의도와 정반대다. 대신 대가를 치른다.

생기 고갈 상태 (누적 단계)

| 단계 | 명줄 | 효과 |
|---|---|---|
| 1 | 0 ~ -10 | 다음 전투방 위협 예산 +1pt, 생기 몰림 발동 -10초 |
| 2 | -11 ~ -25 | +2pt, -20초 |
| 3 | -26 이하 | +3pt, -30초, 방 진입 시 도깨비불 적색 연출 상시 |

- 기존 위협 포인트 예산(ENEMIES 2장)과 생기 몰림(9장)에 그대로 얹는 방식이라 새 시스템을 만들지 않는다
- 보스로 가는 간선은 명줄과 무관하게 항상 열려 있다. 런이 막히는 경로를 원천 차단한다
- 서사: 명줄이 다하면 저승 것들이 산 자임을 알아본다

노드 맵 UI

- 명줄 표시: 남은 명줄, 이번 걸음 비용, 걸은 뒤 남을 명줄을 종이 왼쪽 위에 한 줄로
- 방문한 노드는 붓 동그라미, 현재 노드는 먹 이중 테, 갈 수 있는 노드는 흙빛 후광 + 먹 점선 테
- 자유 이동이라 한 노드가 지나온 곳이면서 갈 수 있는 곳일 수 있다. 두 표시를 선(붓 동그라미)과 면(후광)이라는 다른 채널로 나눠 겹쳐도 읽히게 했다 (2026-08-10). 후광을 종이보다 밝게 하면 배경이 이미 밝아 보이지 않으므로 옅은 흙빛으로 어둡게 깐다

**길 표기 (2026-08-10).** 종전에는 현재 위치에서 갈 수 있는 곳으로만 점선을 찍었다. 지도가 어떻게 이어져 있는지 읽을 수 없어 자유 이동을 판단할 근거가 없었다. 지도의 모든 간선을 옛 지도(대동여지도)의 도로 표기로 긋는다.

| 등급 | 표기 | 뜻 |
|---|---|---|
| 그냥 길 | 가는 점선 1px | 이어져 있다 |
| 지나온 길 | 가는 실선 1px | 실제로 밟았다 (RunMap.is_walked). 발길에 다져져 자국이 이어진 길 |
| 갈 수 있는 길 | 굵은 점선 2px + 십리점 | 지금 걸을 수 있다 |

- 선은 점선이다 (칸 3px, 사이 3px). 옛 지도에서 길은 점을 이어 그렸다. 2026-08-10 사이를 4.5로 잡았다가 성겨 보여 3으로 줄였다
- 지나온 길만 실선이다. 굵기나 색으로 나누면 갈 수 있는 길과 헷갈린다는 지적이 있어(2026-08-10) 선의 종류 자체를 갈랐다. 점선과 실선은 이 해상도에서 확실히 구분된다
- 길은 두 겹으로 굽는다. 전체를 한 번 크게 휘고(최대 2.5px) 그 위에 낮은 물결(2.2px, 1.5~2.5회)을 얹는다. 물결은 양 끝에서 0이 되어 길이 노드에는 곧게 닿는다
- 등급은 색이 아니라 굵기와 점으로 나눈다. 480x270에서 색만으로는 구분되지 않는다
- 선을 긋기 전에 종이색 깔개(3px)를 먼저 깔아, 배경 산수와 손 위에서도 길이 끊겨 보이지 않게 한다
- 십리점은 옛 지도가 도로에 십 리마다 점을 찍어 거리를 알린 표기다. 여기서는 점 하나가 이동 비용 1이다 (COST_UNIT 9px마다 하나)
- 간선 비용 숫자 표기는 폐기했다. 간선마다 숫자를 얹으면 지도가 읽히지 않고, 십리점이 같은 정보를 표기 안에서 전달한다. 정확한 값은 명줄 줄에 있다
- 길은 간선 id로 결정적으로 굽는다(최대 3px). 같은 지도는 같은 굽이를 재현한다
- 미리보기 도구는 tools/pipeline/previz_node_map.py다. Godot 없이 배치와 길 표기를 그대로 렌더한다

### 11.8 생성 검증과 테스트 규칙

tests/unit/test_run_map.gd가 고정한다.

1. 같은 시드는 같은 지도(좌표, 종류, 간선)를 재현한다
2. 모든 간선이 양방향이고 양방향 비용이 같다 (되돌아가기 무제약의 기계적 정의)
3. 방문한 노드와 예산이 모자란 이동도 선택지에서 빠지지 않는다
4. 모든 노드가 시작에서 도달 가능하다
5. 보스는 하나이고 도달 가능하다
6. 이동 비용이 거리 공식과 정확히 일치한다
7. 최단 완주 비용이 예산의 45~85퍼센트 창 (2026-08-10 정정: run_map.gd SHORTEST_RATIO_MIN/MAX 가 기준. 11.4 참고) 안에 든다 (벗어나면 생성기가 다시 그린다)
8. 보상 노드를 전부 도는 비용이 예산을 넘는다
9. 전투가 지도 노드의 50퍼센트를 넘고 신당 1~3, 상점 1~3, 이벤트 2~5다 (2026-08-10 정정: 11.6 범위제. run_map.gd KIND_BANDS 와 COMBAT_SHARE_MIN 이 기준)
10. 보상 노드의 중앙축 이탈 거리가 전투보다 크다
11. 방 위협 예산이 진행도를 따라 오른다
12. 예산을 넘겨 써도 이동이 막히지 않고 고갈 단계만 오른다
13. 경로 재생(replay)으로 예산과 방문 이력이 복원된다
14. 진행도 0.70 이상인 노드는 보스까지 크게 우회하지 않는다 (2026-08-10 정정: 평면 규칙이 우선하므로 직결은 100퍼센트가 아니라 약 64퍼센트다. 11.2 참고. 고정 기준은 우회배율이다) (보스 접근 부채, 11.2)
15. 종류별 개수가 KIND_BANDS 범위 안에 들고 전투가 지도의 50퍼센트 이상이다 (11.6)
16. 시드를 60개 돌리면 지형 틀 다섯 가지가 모두 나오고 노드 수와 신당 수가 갈린다 (11.2, 11.6)
17. 같은 시드는 지형 틀도 같다 (재생성이 걸려도 틀은 유지된다)
18. 길끼리 교차하지 않는다 (평면 그래프, 11.2)
19. 길이 다른 노드를 12px 안쪽으로 스치지 않는다 (11.2)

### 11.9 기존 경로 점수제와의 관계

10장의 P/N 순점수 예산은 폐기하지 않고 역할을 줄인다.

- 이름을 분리한다. 플레이어가 보는 이동 자원은 명줄이고, 10장의 점수는 생성기 내부의 경로 예산이다. UI에 노출하지 않는다
- 상한 검사(B+W)를 폐지한다. 좋은 노드를 많이 밟으려면 명줄을 써야 하므로 운 좋은 경로는 이동 예산이 자연히 제약한다. 상한 검사는 중복이다
- 하한 검사(B-W)만 남긴다. 목적은 하나다. 어떤 경로도 극단적으로 나쁘지 않게 보장한다
- 검사 대상을 한정한다. 자유 이동에서는 경로가 사실상 무한하므로 전수 검사가 성립하지 않는다. 검사는 최단 완주 경로 전체(곁길 없이 전진만 하는 경로들)로만 수행한다. 곁길을 도는 경로는 플레이어가 이득을 보려고 고른 것이므로 하한 보장이 필요 없다

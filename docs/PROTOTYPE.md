# 프로토타입(M1) 범위 정의

최종 수정: 2026-07-23 (2026-07-27 스테일 참조 정정: 층수, 템플릿 수)
상태: 확정 (docs/DECISIONS.md 2026-07-23 참고)

## 1. 목적

- M1의 목표는 재미 검증이다. 조작감(속도감 있는 전투와 이동)과 전투 리듬이 의도대로 나오는지 확인한다
- 통과하지 못하면 M0로 회귀한다 (ROADMAP 기준)
- 절차 생성, 빌드 시스템, 메타 프로그레션은 검증 대상이 아니다

## 2. 캐릭터 컨트롤러 스펙

### 확정 사항

| 항목 | 스펙 |
|---|---|
| 이동 | 지상 가감속. 속도감 우선, 수치는 튜닝 |
| 점프 | 높이 3.5타일, 가변 점프 높이 |
| 공중 제어 | 약화형. 방향 전환 가능, 공중 가속은 지상 대비 크게 낮춤 |
| 코요테 타임 | 포함 |
| 점프 버퍼 | 포함 |
| 벽 점프 | 포함 |
| 이단 점프 | 제외 |
| 대시 | 지상/공중 회피 기동, 무적 프레임 있음, 스태미나 소모, 짧은 후딜레이로 남용 제한 |
| 스태미나 | 대시만 소모 (무적 남용 방지 목적). 회복은 관대하게 시작. 초기 가설: 연속 대시 3~4회 보장, 전투 중에도 빠른 회복. 추후 빌드 축(최대치, 회복 강화) 확장 후보 |

### 설계 원칙

- 의도적으로 접근을 차단한 지형이 아닌 이상 점프(+벽 점프, 대시)로 도달 가능해야 한다
- 도달 가능 판정 기준 수치(점프 3.5타일)에 맞춰 지형 크기를 조정한다. 지형 규격 확정은 맵 설계 단계에서 진행 (추후 결정)
- 스태미나가 속도감을 해치면 회복 속도 상향을 검토한다. 대시 후딜레이 길이는 M1 튜닝 대상 (둘 다 M1 검증 항목)

## 3. 검증용 전투 1종: 기본 총 + 총검

- 설정 근거: 주인공은 현대 한국인(군필). 총기와 총검술 숙련의 서사적 근거 (DECISIONS 시대 설정 참고)
- 원거리: 기본 총. 정해진 탄수 발사 후 재장전 필요. 탄창 소진 시 자동 재장전, 수동 선장전(R) 가능 (2026-07-29 M1 판정 반영). 재장전 중 이동 가능하나 감속
- 근접: 총검 타격. 탄약 소모 없음. 재장전 중에도 사용 가능
- 검증 의도: 무기 1종으로 GDD 7장의 근접과 원거리 하이브리드 체감을 검증한다. 탄약 관리와 재장전-근접 전환이 전투 리듬을 만드는지 확인
- 장기 방침: 본편에서는 검 등 근거리가 메인 후보. 총은 원거리 무기 후보로 유지 (2026-07-25 무기 2슬롯이 자유 조합으로 바뀌어 슬롯 고정 표현을 정정)
- M1 제외: 몸주신 액티브 입력(GDD 6장, 2026-07-25 추가)은 M2 신내림 구현 시 붙인다. M1 조작 검증 범위에 포함하지 않는다

## 4. 테스트 스테이지

### 1단계: 검증용 방 2개

- 절차 생성 없이 수제작
- 전투방 1개 + 플랫포밍방 1개를 입출구 규격으로 연결
- 목적: 조작과 전투 검증, 방 연결 규격(입출구 위치, 방 크기 단위) 초안의 실물 검증. 이 규격이 M2 방 템플릿 19개의 기준이 된다

### 2단계: 1막 러프 구성 (프로토타입 완성 기준)

- 수제 방 6개를 고정 루트(일직선)로 연결한다. 조작과 전투 검증용 축약 구성으로, 실제 1막(9층)의 축소판이다 (M1 범위는 6방, ROADMAP 기준)
- 방 구성: 전투방 중심, 플랫포밍방 포함, 선택방은 자리만 표시 (기능 없음)
- 보스 제외 (M2에서 진행)
- 노드 맵 UI 없음. 방 출구에서 다음 방으로 직결

### 적 (임시 그래픽)

- 돌진형 1종: 잡도깨비 (GDD 7장 1막 아키타입)
- 원거리형 1종: 등불 도깨비
- AI는 최소 구현. 패턴 다양성보다 전투 리듬 검증이 목적

### 데스매치 타이머 (생기 몰림)

- 간단 구현으로 포함: 전투방 타이머 + 초과 시 쌍방 공격력 배율 (적이 더 가파름, 상한 있음)
- 초기 가설: 90초 발동 (RUN_STRUCTURE.md 9장)

## 5. 통과 기준

| 번호 | 기준 | 판정 방법 |
|---|---|---|
| 1 | 조작 반응 | 코요테 타임, 점프 버퍼, 가변 점프가 의도대로 동작. 입력 반응이 즉각적이라고 체감 |
| 2 | 속도감 | 전투방 1개 클리어 평균 60~90초 |
| 3 | 전투 리듬 | 재장전과 총검 전환이 흐름을 끊지 않고 리듬을 만든다고 체감 |
| 4 | 반복 내성 | 동일 스테이지 10분 반복 플레이에 지루함 없음 |
| 5 | 데스매치 체감 | 90초 발동 시 압박이 인지되고 불쾌하지 않음 |

- 판정자: 개발자 본인 플레이. 가능하면 외부 1인 이상 교차 확인
- 5개 중 1, 2, 3은 필수. 4, 5는 수치 튜닝으로 개선 가능하면 조건부 통과
- 미통과 시 M0로 회귀해 컨셉 또는 조작 방향을 재검토한다

## 6. 제외 목록

유물, 신내림 권능, 메타 프로그레션(여의주 조각, 영구 업그레이드), 절차 생성, 노드 맵 UI, 상점과 경제(엽전), 보스, 허브와 NPC, 세이브, 사운드와 음악, 실제 아트(임시 그래픽만 사용)

## 7. 산출물 목록

- 플레이어 씬과 컨트롤러 스크립트 (스태미나 포함)
- 무기 스크립트: 기본 총 (발사, 탄창, 재장전, 총검 타격)
- 적 씬 2종 (돌진형, 원거리형)
- 방 씬: 검증용 2개, 이후 1막 러프 6개
- 방 연결 규격 초안 문서 (방 크기 단위, 입출구 위치 규칙)
- 데스매치 타이머 컴포넌트
- 검증 기록: 통과 기준 5개 판정 결과를 PROGRESS.md에 기록

## 8. 검증 절차

- Cowork(Mac)에서 씬과 스크립트 작성, tools/check.py 통과 확인
- Windows에서 플레이 테스트. 통과 기준 5개 판정과 수치 튜닝 (docs/HARNESS.md 절차)
- 튜닝 대상 파라미터는 export 변수로 노출해 에디터에서 조정 가능하게 작성한다

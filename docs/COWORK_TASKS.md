# Cowork 예약 작업 정의

게임 개발 환경(집, Windows)의 Claude에 적용할 예약 작업 모음이다.
적용 방법: 해당 환경에서 이 파일을 열고 "hgp-weekly-report 예약 작업을 등록해줘"라고 요청한다.
참고: 예약 작업은 앱이 실행 중일 때 동작하며, 예정 시각에 앱이 꺼져 있었다면 다음 실행 시 수행된다.

---

## hgp-weekly-report

- 주기: 매주 월요일 09:00 (cron: 0 9 * * 1)
- 설명: hgp 주간 진행 리포트를 생성해 docs/PROGRESS.md에 기록

프롬프트:

hgp 게임 프로젝트(Godot 4.x 로그라이크 2D 액션 플랫포머, 상용 출시 목표)의 주간 진행 리포트를 작성하라.

절차:
1. 연결된 hgp 폴더에서 git log --since="7 days ago" --oneline --stat 을 실행해 지난 7일간 커밋을 확인한다. 커밋이 없으면 "커밋 없음"으로 기록한다.
2. docs/ROADMAP.md와 docs/PROGRESS.md를 읽어 현재 마일스톤과 직전 상태를 파악한다.
3. 다음 구성으로 리포트를 작성한다.
   - 지난주 완료 항목 (커밋과 문서 기준)
   - 로드맵 대비 현재 위치 (현재 마일스톤, 남은 체크 항목)
   - 이번 주 권장 작업 (3개 이내, 로드맵 순서 기준)
   - 리스크 또는 정체 항목 (해당 시)
4. 작성한 리포트를 docs/PROGRESS.md의 구분선(---) 바로 아래에 "## YYYY-MM-DD 주간 리포트" 제목으로 삽입한다. 기존 내용은 삭제하지 않는다.
5. 리포트 요약을 사용자에게 전달한다.

작성 규칙: 업무적 한국어, 사실 중심, 간결하게. 이모지와 장식용 특수기호 금지. 추측으로 진행 상황을 부풀리지 않는다.

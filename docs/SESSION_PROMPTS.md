## M1. Mac 실행과 판정 (게임 개발 세션)

```
M1 프로토타입의 Mac 실행과 판정을 진행한다. docs/MAC_SETUP.md, docs/M1_CHECKLIST.md, docs/PROTOTYPE.md를 먼저 읽어라.

상황:
- M1 스켈레톤은 구현 완료 상태다 (2026-07-27, 정적 검사와 gdUnit4 5스위트 27케이스 통과). 엔진 로딩과 플레이는 미검증이다
- 개발 환경은 이 Mac이다 (2026-07-29 전환). 네가 수정한 파일은 같은 폴더라 Godot 에디터에 바로 반영된다

진행 방식:
1. 내가 MAC_SETUP.md를 1장부터 수행한다. 막히는 지점의 터미널 출력이나 에러를 붙여넣으면 해결책을 제시하라
2. 에디터에서 파싱 에러, 씬 로드 경고가 나오면 원문을 붙여넣는다. 원인을 찾아 파일을 수정하고, .gd/.tscn/.tres 수정 시 python tools/check.py 통과를 확인한 뒤 보고하라
3. M1_CHECKLIST.md 3장 스모크 13항목을 순서대로 진행한다
4. 4장 통과 기준 5개를 판정한다. 체감 문제는 5장 튜닝 지점의 export 파라미터로 조정안을 제시하라. 수치 변경은 근거와 함께
5. 판정 중 다음 보류 지적 5건도 체감을 확인한다: 카메라 limit 부재(방 밖이 보임), 적 인지가 방 경계 무시, 총검 경직 0.40초, 대시 입력 버퍼 부재, debug_restart F5와 에디터 단축키 중복

규칙:
- 판정 결과와 튜닝 수치는 docs/PROGRESS.md에 기록하라. 통과 시 ROADMAP M1 항목 체크, 미통과 시 M0 회귀를 논의한다
- 설계 문서(DESIGN_ACT1, act1/, systems/)는 동결 상태다. 플레이 체감이 근거일 때만 수정을 제안하고, 수정 전 DECISIONS.md에 기록하라
- 커밋과 push는 내가 직접 한다. 네가 커밋하지 마라
```

## A1. 아트 파이프라인 외부 API 개정 (아트 세션, M1 판정 후)

```
아트 파이프라인을 외부 API 중심으로 개정한다. docs/ART_PIPELINE.md, docs/ART_PIPELINE_SETUP.md, docs/DECISIONS.md의 2026-07-29 Mac 전환 결정과 2026-07-27 PixelLab 결정, docs/GDD.md 10장을 먼저 읽어라.

배경:
- 개발 환경이 Mac으로 전환되며 로컬 ComfyUI(Windows RTX GPU) 경로가 폐기됐다 (2026-07-29 결정)
- 기존 문서는 로컬 생성 중심 + PixelLab 하이브리드 구조라 전면 개정이 필요하다
- 아트 방향(픽셀아트), 막별 팔레트 그라데이션, 요청서 기반 반복 구조는 유지한다

이 세션에서 결정하고 작성할 것:
1. ART_PIPELINE.md 개정: ComfyUI 전제 장들을 외부 API 중심으로 재작성. 5단계 구조(스타일 정의, 생성, 후처리, 수작업 마감, 임포트 검증)의 유지 여부 판단
2. 캐릭터와 적 스프라이트: PixelLab 경로 확정 (기존 결정 유지). 구독 시작 시점 결정
3. 타일과 UI 제작 방식 결정 (미결정 항목): 외부 API 후보 조사(PixelLab 타일 기능 포함), Mac ComfyUI(Apple Silicon) 잔존 옵션, 수작업 병행 중 비교해 선택하라. 비용과 반복 속도 기준
4. ART_PIPELINE_SETUP.md 재작성: Windows 절차를 걷어내고 Mac 기준으로. PixelLab 가입, API 키 관리(.env, 커밋 금지), 첫 생성 테스트 절차
5. 후처리 스크립트(tools/pipeline/postprocess.py)의 외부 API 출력 대응 여부 점검
6. M2 소비처 기준 우선순위 재확인: ROADMAP M2는 UI와 타일 우선이다
7. 비용 추정: 월 구독과 종량 호출 기준으로 M2 기간 예상 비용

산출물: ART_PIPELINE.md와 ART_PIPELINE_SETUP.md 개정, 결정은 DECISIONS.md, 완료는 PROGRESS.md 기록. GDD 10장 표기 동기화. 커밋은 내가 직접 한다
```
